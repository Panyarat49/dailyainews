# Perspectives — 2026-07-13 (ainews)

## 1. DeepSeek ลดราคา 75% แต่ปัญหาต้นทุน 100 เท่ายังอยู่
**อาจารย์ (มหาวิทยาลัย):** เคสนี้เป็นตัวอย่างที่ดีในการสอนเศรษฐศาสตร์ซอฟต์แวร์ยุค AI — สมมติฐานเดิมที่ว่า "โครงสร้างพื้นฐานถูกลง แอปพลิเคชันจะดีขึ้นโดยต้นทุนลดลงตาม" ใช้ไม่ได้อีกต่อไปเมื่อ agentic system บริโภค token เพิ่มขึ้นเร็วกว่าราคาที่ลดลง ควรนำมาถกในชั้นเรียนเรื่อง unit economics ของผลิตภัณฑ์ AI
**ผู้เชี่ยวชาญด้าน AI:** การลดราคา inference ไม่ได้แปลว่าต้นทุนรวมลดลง เพราะ agent แบบ multi-step ยิ่งมีความสามารถสูงยิ่งเรียกโมเดลถี่ขึ้นและยาวขึ้น (การวน reasoning, tool-call หลายรอบ) — ตัวเลข 75% ที่ลดจึงถูกกลืนไปกับ token volume ที่โตเร็วกว่าหลายเท่า
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ build บน agentic workflow ต้องเลิกมองแค่ price-per-token แล้วต้อง track cost-per-task จริง พร้อมใส่ budget cap และ early-exit logic ในทุก agent loop ไม่งั้นบิลจะพุ่งแม้ราคาต่อ token จะถูกลงก็ตาม

## 2. IMF ยกไทยติด 1 ใน 4 ผู้ส่งออกฮาร์ดแวร์ AI ของโลก
**อาจารย์ (มหาวิทยาลัย):** ตัวเลขนี้ควรใช้สอนเศรษฐศาสตร์การพัฒนาว่า "ผู้ส่งออกฮาร์ดแวร์" กับ "ผู้พัฒนาเทคโนโลยี AI" เป็นคนละชั้นของห่วงโซ่มูลค่า — ไทยอยู่ในกลุ่มประกอบ/ผลิตชิ้นส่วน ไม่ใช่กลุ่มออกแบบหรือวิจัยโมเดล คำถามสำหรับนักเรียนคือทำอย่างไรให้ขยับขึ้นห่วงโซ่มูลค่าได้จริง
**ผู้เชี่ยวชาญด้าน AI:** สถานะ "ผู้ส่งออกฮาร์ดแวร์ AI" มักสะท้อนโรงงานประกอบ/ทดสอบชิ้นส่วนที่ป้อนให้ supply chain ของ Nvidia/AMD มากกว่าขีดความสามารถ R&D ภายในประเทศ ตัวเลข GDP ที่ดีขึ้นจึงเป็นผลจาก capex รอบโลกของ AI datacenter ไม่ใช่ตัวชี้วัดความก้าวหน้าด้าน AI ของไทยเอง
**โปรแกรมเมอร์มืออาชีพ:** กระแสนี้อาจสร้างงานด้าน hardware/firmware testing และ supply-chain software ในไทยเพิ่มขึ้น วิศวกรซอฟต์แวร์ที่สนใจสาย embedded หรือ manufacturing IT ควรจับตาการลงทุนโรงงานใหม่ที่มักตามมาด้วยดีมานด์ระบบ MES/automation

## 3. มรดกจากโปรเจกต์รถยนต์ไร้คนขับที่ล้มเหลวของ Apple กลายเป็นชิป AI ทรงพลัง
**อาจารย์ (มหาวิทยาลัย):** กรณีนี้เป็นตัวอย่างคลาสสิกของ "spin-off benefit" ในการวิจัยองค์กร — โครงการที่ถูกยกเลิกไม่ได้แปลว่าล้มเหลวเปล่าประโยชน์ เพราะองค์ความรู้และการลงทุนด้าน on-device AI silicon ถูกนำมาต่อยอดเป็นผลิตภัณฑ์อื่น เหมาะเป็นเคสสอนเรื่อง R&D portfolio management
**ผู้เชี่ยวชาญด้าน AI:** การที่ระบบขับขี่อัตโนมัติต้องประมวลผล sensor fusion แบบเรียลไทม์ผลักดันให้ Apple ลงทุนหนักด้าน on-device inference ตั้งแต่เนิ่น ๆ ซึ่งกลายเป็นรากฐานของชิป M-series ที่เน้น neural engine และหน่วยความจำขนาดใหญ่อย่าง M7 Ultra ที่รองรับ RAM สูงถึง 1.5TB
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาที่เล็ง local/on-device AI บน macOS ควรติดตามสเปก M7 Ultra ใกล้ชิด เพราะ RAM ระดับ 1.5TB เปิดทางให้รันโมเดลขนาดใหญ่บนเครื่อง Mac โดยไม่ต้องพึ่ง cloud inference ซึ่งเปลี่ยนสมการต้นทุนสำหรับแอปที่ต้องการความเป็นส่วนตัวสูง

## 4. ผู้ผลิตหน่วยความจำติดอยู่ในวงจรบูม-บัสต์ที่ AI เร่งให้แรงขึ้น
**อาจารย์ (มหาวิทยาลัย):** วงจร boom-bust ของอุตสาหกรรมหน่วยความจำเป็นกรณีศึกษาคลาสสิกด้าน cyclical industry economics — น่าสนใจว่าดีมานด์จาก AI datacenter ทำให้รอบวงจรครั้งนี้รุนแรงกว่าทุกครั้งที่ผ่านมาหรือไม่ และประวัติศาสตร์อุตสาหกรรมนี้บอกอะไรเกี่ยวกับความเสี่ยงจาก AI capex ที่พึ่งพา supply chain ตัวเดียว
**ผู้เชี่ยวชาญด้าน AI:** รายได้ที่พุ่งขึ้น 2-3 เท่าของ SK Hynix, Micron และ Samsung สะท้อนว่า HBM และ DRAM ความจุสูงกลายเป็นคอขวดจริงของการสร้าง AI cluster ไม่ใช่แค่ GPU — แต่ historically เมื่อผู้ผลิตขยายกำลังผลิตตามดีมานด์ที่ร้อนแรง มักตามมาด้วยภาวะ oversupply เมื่อการลงทุน AI ชะลอตัว
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่วางแผนจัดซื้อฮาร์ดแวร์ AI ระยะยาวควรตั้งงบสำรองรับความผันผวนราคาหน่วยความจำ และพิจารณา cloud/rental GPU มากกว่าการซื้อขาดในช่วงที่ราคา HBM ยังพุ่งสูงจากดีมานด์ล้นตลาด

## 5. Bun พอร์ตโค้ดจาก Zig เป็น Rust สำเร็จใน 11 วัน ด้วยพลัง Fable 5
**อาจารย์ (มหาวิทยาลัย):** ควรใช้เคสนี้สอนเรื่องขีดจำกัดและศักยภาพของ AI-assisted software migration — การพอร์ต runtime ขนาดใหญ่ข้ามภาษาโปรแกรมมิ่งภายใน 11 วันเป็นตัวเลขที่น่าตื่นเต้น แต่ต้องตั้งคำถามต่อว่าคุณภาพโค้ดและ test coverage หลังพอร์ตเทียบเท่าของเดิมหรือไม่
**ผู้เชี่ยวชาญด้าน AI:** การใช้ Fable 5 ช่วยพอร์ตโค้ดระดับ systems programming (Zig → Rust) ที่ต้องจัดการ memory safety และ FFI boundary จำนวนมาก แสดงว่าโมเดลรุ่นใหม่เริ่มรับมือกับงาน refactor ระดับ codebase ทั้งระบบ ไม่ใช่แค่ snippet เล็ก ๆ อีกต่อไป
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่กำลังพิจารณา migrate codebase ขนาดใหญ่ข้ามภาษาควรศึกษาวิธีที่ทีม Bun ใช้ AI ช่วยแบบ incremental พร้อม test suite คุมคุณภาพ เพราะนี่คือ playbook ที่ใช้ได้จริงสำหรับ migration project อื่น ไม่ใช่แค่ hype
