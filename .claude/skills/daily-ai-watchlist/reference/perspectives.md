# Perspectives — 2026-09-02 (watchlist)

## 1. AMD — EuroHPC signs €387.8M contract for AMD-powered "LUMI-AI" supercomputer
**อาจารย์ (มหาวิทยาลัย):** โครงการนี้ชี้ให้เห็นว่ายุโรปกำลังลงทุนโครงสร้างพื้นฐาน AI ของตัวเองอย่างจริงจัง แทนที่จะพึ่งพา cloud ของสหรัฐฯ ทั้งหมด เป็นประเด็นอธิปไตยทางเทคโนโลยีที่น่าสอนในชั้นเรียนนโยบาย
**ผู้เชี่ยวชาญด้าน AI:** การที่โครงการระดับชาติขนาดนี้เลือกชิป AMD Instinct MI430X แทน Nvidia เป็นสัญญาณว่าตลาด AI accelerator กำลังมีคู่แข่งที่แข่งขันได้จริงมากขึ้น ไม่ใช่ตลาดผูกขาดรายเดียวอีกต่อไป
**โปรแกรมเมอร์มืออาชีพ:** กำลังประมวลผล AI ที่เพิ่มขึ้น 10 เท่าในฟินแลนด์ หมายถึงนักวิจัยและสตาร์ทอัพยุโรปจะมีทางเลือกด้าน compute มากขึ้น ลดการพึ่งพา cloud provider สหรัฐฯ ฝั่งเดียว

## 2. Tesla — Cybercab robotaxi launches into a public fight with Waymo over self-driving safety
**อาจารย์ (มหาวิทยาลัย):** การปะทะกันระหว่าง Waymo กับ Tesla เรื่องแนวทาง end-to-end AI กับระบบเซนเซอร์ผสม เป็นตัวอย่างที่ดีของการถกเถียงเชิงวิศวกรรมความปลอดภัยที่ยังไม่มีข้อสรุปทางวิชาการชัดเจน
**ผู้เชี่ยวชาญด้าน AI:** ข้อกล่าวหาของ Waymo ว่าระบบ end-to-end ล้วนๆ ของ Tesla ไม่ปลอดภัยพอ สะท้อนความแตกต่างเชิงสถาปัตยกรรมจริง — Tesla เดิมพันกับกล้องและโมเดลเดียวจบ ส่วน Waymo ยังใช้เซนเซอร์หลายชนิดร่วมกัน ผลจะชัดเจนขึ้นเมื่อ Cybercab เริ่มให้บริการจริงในวงกว้าง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่พัฒนาระบบขับขี่อัตโนมัติควรจับตาข้อมูลความปลอดภัยที่จะทยอยออกมาหลัง Cybercab เปิดตัว 3 กันยายน เพื่อประเมินว่าแนวทาง pure end-to-end นั้น scale ได้จริงในสภาพถนนจริงหรือไม่

## 3. Alibaba — QwenWork AI-agent platform goes global
**อาจารย์ (มหาวิทยาลัย):** การรวมบริการ agent สามตัว (QoderWork, MuleRun, Wukong) เป็นแพลตฟอร์มเดียวแล้วขยายสู่ตลาดเอเชีย ตะวันออกกลาง และลาตินอเมริกา เป็นกรณีศึกษาที่ดีเรื่องกลยุทธ์ผนวกผลิตภัณฑ์ก่อนบุกตลาดต่างประเทศ
**ผู้เชี่ยวชาญด้าน AI:** QwenWork เป็นความพยายามของ Alibaba ที่จะแข่งกับ agentic AI ของฝั่งตะวันตกอย่างจริงจัง โดยใช้จุดแข็งด้านระบบนิเวศ Qwen และ DingTalk ที่มีองค์กรใช้งานอยู่แล้วกว่า 20 ล้านราย
**โปรแกรมเมอร์มืออาชีพ:** การที่ agent สั่งงานผ่านภาษาธรรมชาติแล้วควบคุมคอมพิวเตอร์/เว็บไซต์แทนผู้ใช้ได้โดยตรง เป็นรูปแบบ automation ที่ทีมองค์กรควรทดสอบเทียบกับเครื่องมือ agent ฝั่งตะวันตกก่อนตัดสินใจใช้งานจริง

## 4. Apple — Tim Cook hands CEO role to John Ternus, Siri overhaul next
**อาจารย์ (มหาวิทยาลัย):** การเปลี่ยนผู้นำองค์กรขนาดนี้เป็นตัวอย่างคลาสสิกของการวางแผนสืบทอดตำแหน่งที่เตรียมการมาหลายเดือน ไม่ใช่การตัดสินใจฉับพลัน
**ผู้เชี่ยวชาญด้าน AI:** Ternus มาจากสายฮาร์ดแวร์ ไม่ใช่สาย AI/ซอฟต์แวร์โดยตรง งานแรกที่ทุกคนจับตาคือ Siri เวอร์ชันใหม่ในงาน 9 กันยายน ซึ่งจะเป็นบทพิสูจน์ว่า Apple ตามคู่แข่งอย่าง OpenAI และ Anthropic ทันหรือไม่
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาที่ทำแอปบน iOS ควรจับตาทิศทางกลยุทธ์ AI ของผู้บริหารใหม่ เพราะอาจกระทบ API และเครื่องมือ agentic ที่ Apple จะเปิดให้นักพัฒนาใช้ต่อจากนี้
