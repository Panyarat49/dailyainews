# Perspectives — 2026-09-11 (watchlist)

## 1. Nvidia (NVDA · Tier 1) — Australia 2GW AI-factory buildout
**อาจารย์ (มหาวิทยาลัย):** ตัวอย่างที่ดีของการสอนเรื่อง AI infrastructure ว่าการแข่งขันด้าน AI ไม่ได้อยู่แค่ที่โมเดล แต่รวมถึงพลังงานและศูนย์ข้อมูลระดับประเทศ
**ผู้เชี่ยวชาญด้าน AI:** การผูกพันธมิตรแปดรายพร้อมกันในประเทศเดียวสะท้อนว่า Nvidia กำลังเร่งสร้าง capacity นอกสหรัฐฯ เพื่อกระจายความเสี่ยงด้านพลังงานและ supply chain ให้ DSX platform
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่วางแผนงบ GPU cloud ระยะยาวควรจับตาราคาและ availability ของ capacity ในภูมิภาค APAC ที่จะเพิ่มขึ้นชัดเจนภายในปี 2570

## 2. Apple (AAPL · Tier 1) — A20 Pro ชิป 2nm ตัวแรก
**อาจารย์ (มหาวิทยาลัย):** ใช้สอนเรื่องความสัมพันธ์ระหว่างความก้าวหน้าด้าน semiconductor process node กับความสามารถ on-device AI ที่ผู้บริโภคสัมผัสได้จริง
**ผู้เชี่ยวชาญด้าน AI:** การเปลี่ยนจาก FinFET ไป gate-all-around ที่ 2nm ให้ทั้งประสิทธิภาพต่อวัตต์ที่ดีขึ้นและพื้นที่ชิปมากขึ้นสำหรับ Neural Engine ซึ่งหนุน on-device AI ได้แรงขึ้นโดยไม่ต้องพึ่ง cloud
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาแอปที่รันโมเดล AI บนตัวเครื่อง เช่น งานภาพหรือวิดีโอ ควรทดสอบ benchmark ใหม่บน A20 Pro เพราะช่องว่างด้าน compute/latency เมื่อเทียบรุ่นก่อนจะกว้างขึ้นชัดเจน

## 3. Alphabet (GOOGL · Tier 1) — AlphaGenome Atlas
**อาจารย์ (มหาวิทยาลัย):** เป็นตัวอย่างชั้นดีของ AI for Science — เปิด dataset ระดับเพตะไบต์ให้ใช้ฟรีเพื่อการวิจัย เหมาะสอนเรื่องบทบาท AI ในงานวิทยาศาสตร์พื้นฐาน
**ผู้เชี่ยวชาญด้าน AI:** การให้คะแนนครอบคลุมการเปลี่ยนแปลง DNA เกือบทุกจุดที่เป็นไปได้เปลี่ยนงานวิจัยพันธุศาสตร์จากการค้นหาทีละตัวแปรเป็นการตั้งสมมติฐานอัตโนมัติผ่าน AI assistant
**โปรแกรมเมอร์มืออาชีพ:** ทีม bioinformatics หรือ health-tech ควรลองต่อ AlphaGenome API เข้ากับ pipeline วิเคราะห์ variant ที่มีอยู่ เพื่อลดเวลาประมวลผลจากหลักสัปดาห์เหลือหลักนาที

## 4. Meta Platforms (META · Tier 1) — เปิดตัว Muse personal AI agent
**อาจารย์ (มหาวิทยาลัย):** กรณีศึกษาที่ดีเรื่องความไว้วางใจของผู้ใช้เมื่อ AI agent เข้าถึงอีเมล ปฏิทิน และข้อมูลการชำระเงินแทนตัวผู้ใช้เอง
**ผู้เชี่ยวชาญด้าน AI:** การให้ agent แต่ละตัวรันอยู่ใน virtual machine ของตัวเองเพื่อทำงานต่อเนื่องแม้ผู้ใช้ออกจากแอปไปแล้ว เป็นสถาปัตยกรรมที่ต่างจาก chatbot ทั่วไป และต้องแลกกับความเสี่ยงด้านความปลอดภัยของข้อมูลที่มากขึ้น
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่สร้างผลิตภัณฑ์ agent ที่ต้องเชื่อมต่อบัญชีผู้ใช้ (อีเมล ปฏิทิน การชำระเงิน) ควรศึกษาโมเดล permission และ connector ของ Muse เป็นแนวทางออกแบบระบบ consent และการจำกัดสิทธิ์เข้าถึง
