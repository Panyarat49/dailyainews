# Perspectives — 2026-09-28 (watchlist)

## 1. Microsoft — Copilot revamp: "Code" generation tool + "Autopilot" always-on agent
**อาจารย์ (มหาวิทยาลัย):** ตัวอย่างที่ดีของการสอนเรื่องวิวัฒนาการจาก "AI ผู้ช่วย" (assistant) ไปสู่ "AI ตัวแทน" (agent) ที่มีตัวตนและสิทธิ์ของตัวเองในองค์กร นักเรียนควรวิเคราะห์ผลกระทบต่อโครงสร้างงานสำนักงาน
**ผู้เชี่ยวชาญด้าน AI:** การให้ Autopilot มี identity แยกใน company directory พร้อม permission ที่ควบคุมได้ เป็นการออกแบบที่จริงจังกว่าการ demo ทั่วไป แต่ยังต้องรอดูว่าการจัดการสิทธิ์และ audit trail ทำได้ปลอดภัยแค่ไหนเมื่อใช้งานจริง
**โปรแกรมเมอร์มืออาชีพ:** เครื่องมือ "Code" ที่ใช้เทคโนโลยีเดียวกับ GitHub Copilot หมายความว่าทีมพัฒนาควรเตรียมประเมิน governance สำหรับแอปที่ non-engineer สร้างขึ้นเอง (shadow IT ระลอกใหม่) ก่อนที่จะปล่อยให้พนักงานทั่วไปเข้าถึงในวงกว้าง

## 2. AMD — Market cap crosses $1 trillion for the first time
**อาจารย์ (มหาวิทยาลัย):** ใช้สอนเรื่องการประเมินมูลค่าบริษัทเทคโนโลยีในยุค AI boom และเปรียบเทียบเส้นทางของ AMD กับ Nvidia/Broadcom/Micron ที่ผ่านหลักหมื่นล้านล้านมาก่อน
**ผู้เชี่ยวชาญด้าน AI:** การเติบโตของรายได้ราว 50% มาจากดีมานด์ชิป AI เป็นหลัก สะท้อนว่าตลาดยังเชื่อว่า AMD จะเป็นทางเลือกที่สองรองจาก Nvidia ในตลาด accelerator ระดับ data center ได้จริง ไม่ใช่แค่กระแสหุ้น
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่วางแผน infra ระยะยาวควรจับตาความพร้อมของ ROCm software stack ของ AMD เทียบกับ CUDA เพราะมูลค่าตลาดที่สูงขึ้นไม่ได้แปลว่า tooling จะสมบูรณ์ตามไปด้วยในทันที

## 3. Alibaba — Unveils Zhenwu V900, its most powerful AI chip yet
**อาจารย์ (มหาวิทยาลัย):** ตัวอย่างที่ดีในการสอนเรื่องผลกระทบของมาตรการควบคุมการส่งออกชิปสหรัฐฯ ต่อการพัฒนาเทคโนโลยีในประเทศจีน และการแข่งขันด้าน compute ระดับภูมิรัฐศาสตร์
**ผู้เชี่ยวชาญด้าน AI:** สเปกอย่างหน่วยความจำ 216GB บนชิปและแบนด์วิดท์ 1,200GB/s ที่ขยายเป็นคลัสเตอร์ได้ถึง 500,000 ชิ้น ใกล้เคียงสถาปัตยกรรมระดับ Nvidia Blackwell/Rubin แต่ตัวเลขนี้ยังต้องรอการยืนยันจาก benchmark อิสระ ไม่ใช่แค่ตัวเลขที่บริษัทแถลง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่พัฒนาโมเดลบน stack ของ Alibaba Cloud ควรจับตาความพร้อมของ tooling/compiler สำหรับ Zhenwu เพราะการย้าย workload จาก CUDA มาระบบนิเวศอื่นมักมีต้นทุนด้านวิศวกรรมสูงกว่าที่ตัวเลขฮาร์ดแวร์บ่งชี้

## 4. Meta Platforms — Everything new coming to Muse at Connect 2026
**อาจารย์ (มหาวิทยาลัย):** กรณีนี้ดีสำหรับสอนเรื่องการออกแบบ multimodal agent ที่ผสาน avatar เสียง และอุปกรณ์สวมใส่เข้าด้วยกัน เป็นภาพรวมทิศทางผลิตภัณฑ์ AI ผู้บริโภคของ Meta ในปี 2026
**ผู้เชี่ยวชาญด้าน AI:** การผลักดัน Muse ให้ทำงานข้ามอุปกรณ์ (แว่นตา, Charm, Mac) พร้อมสิทธิ์ควบคุมแอปพลิเคชันจริง หมายถึงพื้นที่เสี่ยงด้าน privacy และ permission ที่กว้างขึ้นมาก เทียบเท่าระดับ OS-level agent
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาที่ต้องการผนวกบริการกับ Muse ผ่านพาร์ทเนอร์ค้าปลีกควรศึกษาข้อกำหนด API/permission model ของ Meta ตั้งแต่ตอนนี้ เพราะการรวมเข้ากับ agent ที่ควบคุมทั้งเดสก์ท็อปมีความซับซ้อนด้าน security สูงกว่าการต่อ API ทั่วไป
