# Perspectives — 2026-07-29 (watchlist)

## 1. Microsoft — MDASH AI bug-hunting agent beats rivals on CyberGym benchmark
**อาจารย์ (มหาวิทยาลัย):** ตัวเลข CyberGym ที่ต่างกันระหว่าง Microsoft (95.95%) และ Wiz (90.9%) เป็นตัวอย่างที่ดีสำหรับสอนนักเรียนให้อ่าน benchmark อย่างมีวิจารณญาณ เพราะเงื่อนไขการทดสอบของแต่ละค่ายอาจไม่เหมือนกันทุกประการ
**ผู้เชี่ยวชาญด้าน AI:** MDASH เอาชนะทั้ง Anthropic Mythos, OpenAI GPT-5.5/5.6 Cyber และ Google Gemini 3.5 Flash Cyber บนเกณฑ์เดียวกัน แสดงว่า Microsoft กำลังจริงจังกับการสร้าง AI security stack ของตัวเองแทนที่จะพึ่งโมเดลจากค่ายอื่น
**โปรแกรมเมอร์มืออาชีพ:** ทีม AppSec ที่ใช้ Azure ควรจับตาว่า MDASH จะถูกผนวกเข้า Defender หรือ GitHub Advanced Security เมื่อไหร่ เพราะการเจอช่องโหว่อัตโนมัติระดับนี้เริ่มพร้อมใช้งานจริงในสายพัฒนาแล้ว

## 2. Amazon — AWS signs $410M multiyear compute deal with Recursive Superintelligence
**อาจารย์ (มหาวิทยาลัย):** ดีลนี้เหมาะสอนความแตกต่างระหว่างการลงทุนแบบ equity ของค่ายใหญ่ (เช่น Microsoft-OpenAI) กับดีล compute-only ที่ไม่มีส่วนได้เสียในบริษัท ซึ่งเป็นอีกโมเดลธุรกิจของ cloud provider
**ผู้เชี่ยวชาญด้าน AI:** แนวทาง "self-improving system ที่เน้น agent count มากกว่า headcount" ของ Recursive Superintelligence สะท้อนเทรนด์ที่บริษัท AI รุ่นใหม่ทุ่มงบเกือบทั้งหมดไปที่ compute แทนที่จะจ้างคน ซึ่งเปลี่ยนโครงสร้างต้นทุนของอุตสาหกรรมไปมาก
**โปรแกรมเมอร์มืออาชีพ:** ดีลขนาด 410 ล้านดอลลาร์ที่ CEO บอกว่า "จะเป็นดีลที่เล็กที่สุด" ในอนาคต บ่งชี้ว่า AWS กำลังเตรียมรับดีล compute ระดับ hyperscale จากสตาร์ทอัพ frontier มากขึ้น ทีมที่วางแผน capacity บน AWS ควรเผื่อความผันผวนของ availability ไว้ด้วย

## 3. AMD — signs deal for up to 2.5GW of AI data-center capacity with Core Scientific
**อาจารย์ (มหาวิทยาลัย):** การที่ Core Scientific เปลี่ยนจากขุด crypto มาเป็นโฮสต์ AI/HPC เต็มตัว เป็นกรณีศึกษาที่ดีเรื่องการ pivot ธุรกิจตามความต้องการพลังงานและโครงสร้างพื้นฐานของอุตสาหกรรม AI
**ผู้เชี่ยวชาญด้าน AI:** การรับ warrant หุ้น Core Scientific แทนเงินสดล้วนแสดงว่า AMD กำลังผูกผลประโยชน์ระยะยาวกับพันธมิตรด้าน data center โดยตรง ไม่ใช่แค่ซื้อ capacity เฉย ๆ ซึ่งต่างจากรูปแบบดีลทั่วไปของคู่แข่ง
**โปรแกรมเมอร์มืออาชีพ:** กำลังการผลิตสูงสุด 2.5GW ที่จะทยอยมาตั้งแต่ปี 2027 หมายความว่าทีมที่วางแผนใช้ AMD Instinct ระยะยาวควรเริ่มประเมิน roadmap ของ Core Scientific เป็นหนึ่งใน location ที่อาจได้ capacity เพิ่ม

## 4. Alphabet — Gemini 3.6 Flash agents help a Michigan dairy farmer automate operations
**อาจารย์ (มหาวิทยาลัย):** เคสนี้เหมาะสอนเรื่อง practical AI adoption นอกภาคเทคโนโลยี — เกษตรกรรายย่อยก็สามารถสร้างระบบ multi-agent เองได้โดยไม่ต้องมีทีมวิศวกรรมขนาดใหญ่
**ผู้เชี่ยวชาญด้าน AI:** ตัวอย่างนี้แสดงจุดแข็งของ Gemini 3.6 Flash ในงาน data-integration ต้นทุนต่ำ — เชื่อมข้อมูลจากเซนเซอร์ปศุสัตว์ สถานีอากาศ และระบบคุณภาพนม ที่แต่เดิมแยกกันเป็น silo เข้าด้วยกันแบบ local-first
**โปรแกรมเมอร์มืออาชีพ:** เป็นตัวอย่างที่ดีของการใช้ agentic workflow แก้ปัญหา ETL แบบ ad-hoc โดยไม่ต้องสร้าง pipeline software เต็มรูปแบบ เหมาะกับทีมขนาดเล็กที่มีข้อมูลกระจัดกระจายหลายแหล่ง

## 5. Tesla — lawsuit alleges Full Self-Driving robotaxis were "rolling hazards"
**อาจารย์ (มหาวิทยาลัย):** คดีนี้เป็นตัวอย่างที่ดีสำหรับสอนประเด็น human oversight ใน autonomous system — เมื่อจำนวนรถต่อผู้ควบคุมความปลอดภัยมากเกินไป ความเสี่ยงด้าน safety จะเพิ่มขึ้นแบบไม่เป็นเชิงเส้น
**ผู้เชี่ยวชาญด้าน AI:** ข้อกล่าวหานี้ตอกย้ำคำถามเดิมเกี่ยวกับความพร้อมของระบบ FSD/robotaxi ของ Tesla ว่า autonomy stack ยังต้องพึ่งการแทรกแซงของมนุษย์มากกว่าที่บริษัทสื่อสารต่อสาธารณะหรือไม่
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่พัฒนาระบบ autonomous หรือ agentic ที่มีคนคอยกำกับ (human-in-the-loop) ควรทบทวนอัตราส่วนคนต่อระบบที่ดูแลอยู่ เพราะคดีลักษณะนี้มักเป็นสัญญาณเตือนล่วงหน้าเรื่อง operational overextension
