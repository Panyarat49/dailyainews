# Perspectives — 2026-07-10 (watchlist)

## 1. Meta Platforms — อัปเดตสำคัญ 3 รายการ

### 1.1 Muse Image sparks Instagram consent backlash
**อาจารย์ (มหาวิทยาลัย):** เหมาะเป็นกรณีศึกษาเรื่อง consent-by-default vs. consent-by-design — การ opt-in อัตโนมัติให้บัญชีสาธารณะทุกบัญชีโดยไม่แจ้งเตือนล่วงหน้าคือรูปแบบที่ตรงข้ามกับหลัก informed consent ที่ควรสอนในหลักสูตร AI ethics
**ผู้เชี่ยวชาญด้าน AI:** ความสามารถ tag บัญชีคนอื่นเพื่อดึงภาพมาสร้างใหม่คือ feature ที่ทางเทคนิคทำได้ง่ายแต่ risk surface สูงมาก — ไม่มี identity verification ว่าใครเป็นคนสั่ง generate ภาพของใคร ต่างจาก generative tool ทั่วไปที่ไม่ผูกกับบัญชีจริง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ build บน Meta AI API ควรตรวจสอบ policy การใช้ @mention นี้อย่างละเอียด และแจ้งผู้ใช้ปลายทางให้ทราบวิธี opt-out ก่อนนำฟีเจอร์แบบนี้ไปต่อยอด เพราะความเสี่ยงด้าน reputational damage สูงกว่าฟีเจอร์ AI ทั่วไป

### 1.2 AI chip เข้าสู่การผลิตกันยายน เพิ่ม compute เป็นสองเท่า
**อาจารย์ (มหาวิทยาลัย):** ตัวอย่างที่ดีของ vertical integration ในสาย AI infrastructure — การออกแบบชิปเองช่วยลดการพึ่งพา Nvidia และควบคุมต้นทุนต่อหน่วยประมวลผลได้มากขึ้นในระยะยาว
**ผู้เชี่ยวชาญด้าน AI:** แนวทาง modular chip design ที่ปรับเปลี่ยนได้ตามความต้องการ AI ที่เปลี่ยนเร็ว ต่างจากการออกแบบชิปแบบ fixed-purpose แต่รายละเอียดสเปกยังไม่ชัดเพราะข่าวมาจาก memo ภายในที่หลุดออกมา ต้องรอการยืนยันอย่างเป็นทางการ
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ Meta AI infrastructure หรือติดตาม capacity ฝั่งคลาวด์ควรจับตาประกาศทางการช่วงกันยายน เพราะการเพิ่ม compute เป็นสองเท่าอาจกระทบราคาและ availability ของบริการที่พึ่งพาโครงสร้างพื้นฐานนี้

### 1.3 Muse Spark 1.1 เปิดขายผ่าน API ครั้งแรก
**อาจารย์ (มหาวิทยาลัย):** เหมาะสอนเรื่อง competitive benchmarking — Meta เข้าตลาด agentic coding ทีหลัง Anthropic และ OpenAI มาก แต่แข่งด้วยกลยุทธ์ราคาแทนคะแนน benchmark ที่เหนือกว่า
**ผู้เชี่ยวชาญด้าน AI:** จุดเด่นทางเทคนิคคือ multi-agent orchestration และ computer-use ควบคุมหลายแอปพร้อมกัน ต่างจากการแข่งแค่ single-agent coding score แม้คะแนนยังตามหลัง Opus/GPT
**โปรแกรมเมอร์มืออาชีพ:** ราคา $1.25/$4.25 ต่อล้านโทเค็นถูกกว่า Claude Haiku 4.5 และ GPT-5.6 Luna เล็กน้อย เหมาะให้ทีมงาน agentic workload ต้นทุนสูงทดลองเทียบคุณภาพจริงคู่ขนานก่อนย้าย

## 2. Microsoft — GPT-5.6 กลายเป็นโมเดลหลักของ Microsoft 365 Copilot
**อาจารย์ (มหาวิทยาลัย):** เหมาะสอนเรื่อง platform dependency — Microsoft ยังคงพึ่งพา OpenAI เป็น default model แม้จะพัฒนา MAI ของตัวเองคู่ขนานไปด้วย สะท้อนความสัมพันธ์ที่ซับซ้อนกว่าคำว่า "คู่แข่งหรือพันธมิตร"
**ผู้เชี่ยวชาญด้าน AI:** การอัปเกรดโมเดลเบื้องหลัง Copilot ทั้ง Word/Excel/PowerPoint/Cowork พร้อมกันแสดงว่า OpenAI ยังคงเป็น infrastructure ระดับ core ของ Microsoft 365 ไม่ใช่แค่ฟีเจอร์เสริม ต้องรอดูว่า performance-per-dollar ที่อ้างจะรู้สึกได้จริงในงานประจำวันหรือไม่
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ build บน Microsoft Graph/Copilot API ควรทดสอบ regression ของ workflow อัตโนมัติที่พึ่งพา output format เดิม เพราะการเปลี่ยนโมเดลเบื้องหลังอาจเปลี่ยนพฤติกรรม output แม้ API เดิมจะไม่เปลี่ยน

## 3. Alphabet — Google เริ่มติดป้าย "สร้างด้วย AI" บนโฆษณา
**อาจารย์ (มหาวิทยาลัย):** สอนเรื่อง transparency-by-design ที่จำกัดเฉพาะเครื่องมือของตัวเอง แต่พึ่ง self-declaration สำหรับเครื่องมือภายนอก เผยข้อจำกัดของการกำกับดูแลตนเองในอุตสาหกรรมโฆษณา
**ผู้เชี่ยวชาญด้าน AI:** นี่คือ metadata label ระดับแพลตฟอร์มที่ผู้ใช้มองเห็นง่าย ต่างจาก watermarking ที่ฝังในไฟล์ แต่ยังไม่มี mechanism บังคับให้ third-party tools ต้องรายงานความจริง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ทำระบบโฆษณาอัตโนมัติควรตรวจสอบว่า pipeline การสร้างครีเอทีฟด้วย AI ของตนติดป้ายตรงตามนโยบายใหม่หรือไม่ ก่อนแพลตฟอร์มโฆษณาอื่นจะออกกฎบังคับตามมา

## 4. Alibaba — ศาลสหรัฐฯ ระงับกฎ Pentagon ชั่วคราว คืนสิทธิ์ล็อบบี้ยิสต์
**อาจารย์ (มหาวิทยาลัย):** เหมาะสอนเรื่องผลกระทบของ export-control/national-security list ต่อความสามารถทางกฎหมายและการเมืองของบริษัทข้ามชาติ ไม่ใช่แค่ผลกระทบทางการค้าโดยตรง
**ผู้เชี่ยวชาญด้าน AI:** การขยาย 1260H list ให้ครอบคลุมบริษัท AI/e-commerce/EV อย่าง Alibaba นอกเหนือจาก defense contractor ดั้งเดิม สะท้อนว่าเส้นแบ่งระหว่าง "AI/tech company" กับ "national-security concern" กำลังพร่าเลือนมากขึ้นในสายตารัฐบาลสหรัฐฯ
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ทำงานกับ Alibaba Cloud หรือ Qwen API ในบริบทที่เกี่ยวข้องกับสหรัฐฯ ควรติดตามผลคดีนี้ต่อเนื่อง เพราะสถานะทางกฎหมายของ Alibaba ในสหรัฐฯ ยังไม่นิ่ง (มีเวลาเพียง 60 วันก่อนศาลตัดสินขั้นสุดท้าย) ซึ่งอาจกระทบ compliance requirement ของโปรเจกต์ที่ integrate กับบริการของ Alibaba
