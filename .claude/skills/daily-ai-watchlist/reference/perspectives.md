# Perspectives — 2026-06-27 (watchlist)

## 1. Nvidia (NVDA · Tier 1) — ทุกยักษ์ใหญ่ตั้งแต่ OpenAI ถึง SpaceX สร้างชิปเอง กดดัน Nvidia มากขึ้น
**อาจารย์ (มหาวิทยาลัย):** การที่ OpenAI, Apple, Google, SpaceX ต่างสร้าง custom silicon ของตัวเอง คือการ replicate playbook ที่ Intel เคยเผชิญเมื่อ Apple ย้ายไป Arm — แต่ครั้งนี้ CUDA moat ของ Nvidia สร้าง switching cost สูงกว่ามาก; กรณีนี้เหมาะนำมาสอน "incumbent defense strategy" และ lock-in economics ในตลาดที่ผู้เล่นรายเดิมมี network effect จาก toolchain
**ผู้เชี่ยวชาญด้าน AI:** Custom silicon จาก hyperscalers คือ strategic hedge ไม่ใช่ abandon Nvidia ทันที — เป้าหมายคือลด single-supplier dependency ระยะยาวขณะยัง production บน CUDA; Nvidia ต้องพิสูจน์ว่า NIM + Blackwell software stack ให้ TCO ที่ดีกว่า custom silicon ที่ tuned เฉพาะ use-case ของแต่ละบริษัท
**โปรแกรมเมอร์มืออาชีพ:** Custom silicon ที่ hyperscalers สร้างไม่ได้เปิดให้ third-party ใช้ — GPU availability risk สำหรับ dev teams ไม่ได้ลดลง; ควรวาง multi-provider GPU strategy บน Nvidia H100/B100 ต่อไปอย่างน้อย 2–3 ปี ขณะประเมิน alternative inference providers (Together AI, Groq, Fireworks) ควบคู่กัน

## 2. Tesla (TSLA · Tier 1) — Tesla ยอมความคดี FSD ชนร้ายแรง NHTSA อัปเกรดสู่ Engineering Analysis
**อาจารย์ (มหาวิทยาลัย):** การ settle โดยไม่เปิดเผย terms หมายความว่า Tesla หลีกเลี่ยง legal discovery ที่บังคับเปิด FSD training data และ internal safety documents — precedent ที่จะออกมาจะกำหนดว่า ADAS liability เป็นของ manufacturer, software developer หรือ driver ใน legal landscape ที่ยังเขียนตัวเองอยู่
**ผู้เชี่ยวชาญด้าน AI:** NHTSA upgrade จาก preliminary investigation สู่ "engineering analysis" เป็น regulatory escalation ที่มีน้ำหนัก — หมายความว่า agency มีหลักฐานพอสมควรเกี่ยวกับ FSD degradation detection failure ใน reduced visibility; ถ้า findings ออกมาเป็น recall หรือ software mandate จะสร้าง precedent ที่ส่งผลต่อ autonomous driving industry ทั้งหมด
**โปรแกรมเมอร์มืออาชีพ:** FSD investigation series ยืนยัน pattern: regulator escalate เมื่อพบ recurring safety failure across incidents — ทีมที่พัฒนา safety-critical AI ต้องออกแบบ "degradation detection in edge conditions" ให้ชัดเจน ไม่ใช่แค่ average-case performance; "appropriate degradation detection" กำลังกลาย de facto regulatory requirement

## 3. Amazon (AMZN · Tier 1) — สหรัฐฯ ปลดล็อก Anthropic Mythos ให้บริษัทสหรัฐฯ บางรายเข้าถึงได้
**อาจารย์ (มหาวิทยาลัย):** รูปแบบ "government releases AI model to approved companies" คือ governance paradigm ใหม่ที่ไม่เคยมีมาก่อน — รัฐทำหน้าที่ gatekeeper กำหนด access policy ต่อ AI capabilities แบบเดียวกับ export control ในยุค semiconductor; นี่คือ case study "AI as strategic asset" ที่ควรสอนควบคู่กับ GPT-5.6 Trump EO
**ผู้เชี่ยวชาญด้าน AI:** รูปแบบ "curated access list" สำหรับ frontier models บ่งชี้ว่า AI governance เปลี่ยนจาก "publish and distribute" เป็น "regulated capability access" — Amazon/AWS ที่ลงทุนใน Anthropic และ host Claude บน Bedrock จะได้ประโยชน์โดยตรงหาก Mythos พร้อมใน Bedrock ก่อนคู่แข่ง
**โปรแกรมเมอร์มืออาชีพ:** ถ้า build บน Claude ผ่าน AWS Bedrock และรอ Mythos: "some US companies" ยังไม่ชัดว่า developer accounts ทั่วไปจะเข้าถึงเมื่อไหร่ — ติดตาม AWS Bedrock changelog และ Anthropic model availability announcements อย่างใกล้ชิด และเตรียม abstraction layer รองรับ model upgrade ได้โดยไม่ต้อง refactor ใหญ่

## 4. Microsoft (MSFT · Tier 1) — SOCAR Türkiye ประหยัด 7,500+ ชั่วโมงต่อปีด้วย Copilot Studio
**อาจารย์ (มหาวิทยาลัย):** 7,500+ ชั่วโมงต่อปีเทียบเท่าพนักงาน full-time ประมาณ 3–4 คน — เป็น data point ที่ quantify ได้ชัดเจนสำหรับสอนวิธีคำนวณ ROI ของ AI deployment อย่างเป็นระบบ กรณีนี้ยังเป็นตัวอย่างดีว่า conservative industry เช่น energy sector เริ่ม adopt enterprise AI อย่างไร
**ผู้เชี่ยวชาญด้าน AI:** SOCAR case บ่งชี้ว่า Microsoft Copilot Studio + Foundry mature พอสำหรับ enterprise deployment ใน non-tech industries — custom chatbot (s.e.d.a.+) ที่ handle travel approval, customer queries และ information retrieval พร้อมกันใน single platform คือ multi-channel AI agent ที่ทำงานได้จริง ไม่ใช่ pilot
**โปรแกรมเมอร์มืออาชีพ:** s.e.d.a.+ architecture บน Copilot Studio + Microsoft Foundry คือ reference implementation สำหรับ enterprise AI assistant — ถ้า build บน Microsoft ecosystem ควรดู Copilot Studio documentation สำหรับ multi-channel agent pattern ก่อน custom implementation; Foundry integration ช่วย enterprise compliance ที่ often blocks custom LLM adoption ได้
