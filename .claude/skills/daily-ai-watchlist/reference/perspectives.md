# Perspectives — 2026-08-25 (watchlist)

## 1. Nvidia — roundup (SpaceXAI/Vera CPU, Vera Rubin NVL72 efficiency, Groq 3 LPX full production)
**อาจารย์ (มหาวิทยาลัย):** ใช้สามข่าวนี้สอนภาพรวมของ "AI factory" แบบครบวงจร — CPU เฉพาะทางสำหรับ agent, ประสิทธิภาพต่อวัตต์ของทั้งแร็ค และชิป inference เฉพาะทาง (Groq) ทำงานประสานกันอย่างไร แทนที่จะมองแต่ละชิ้นแยกกัน
**ผู้เชี่ยวชาญด้าน AI:** ตัวเลข 30 เท่าของ throughput ต่อเมกะวัตต์และ 35 เท่าของต้นทุนต่อ token ที่ลดลง เทียบกับ GB300 NVL72 รุ่นก่อน เป็นก้าวกระโดดที่ใหญ่ผิดปกติในรอบเดียว ควรตรวจสอบเงื่อนไขการวัดผล (agentic coding trajectories) ว่าครอบคลุม workload อื่นด้วยหรือไม่
**โปรแกรมเมอร์มืออาชีพ:** การที่ Groq 3 LPX เข้าสู่ full production พร้อมตัวเลขเบนช์มาร์กที่ยืนยันจาก Artificial Analysis ทำให้ทีมที่วางแผน migrate งาน long-context inference ควรเริ่มประเมินเส้นทางการเข้าถึง Vera Rubin/LPX rack และเทียบราคากับ GPU สแตนดาร์ดที่ใช้อยู่

## 2. Alibaba — Wan3.0 หลังระดมทุน AI 3.3 แสนล้านบาท
**อาจารย์ (มหาวิทยาลัย):** เป็นตัวอย่างชัดเจนของการผูก capital markets เข้ากับ product roadmap โดยตรง — ระดมทุนแล้วประกาศชัดว่าเงินจะไปที่ AI infra จากนั้นออกผลิตภัณฑ์ตามมาในเวลาไม่ถึงสัปดาห์
**ผู้เชี่ยวชาญด้าน AI:** Wan3.0 ที่สร้างวิดีโอได้ยาวถึง 30 วินาทีและรับ input หลายรูปแบบ (เอกสาร, สเปรดชีต, สไลด์) วางตำแหน่งแข่งกับ Google Veo โดยตรง เป็นสัญญาณว่าโมเดล video generation จากจีนกำลังไล่ตามคู่แข่งตะวันตกเร็วขึ้น
**โปรแกรมเมอร์มืออาชีพ:** ราคา API ที่ $0.05-0.20 ต่อวินาทีตามความละเอียด (คลิป 1080p ยาว 30 วินาทีราว $6) เป็นข้อมูลที่ทีมทำ media/marketing content ควรนำไปเทียบต้นทุนกับ Veo หรือ Sora ก่อนเลือกใช้งานจริง

## 3. Microsoft — ASSERT และ ACS สำหรับกำกับดูแล AI agent
**อาจารย์ (มหาวิทยาลัย):** เหมาะสอนความต่างระหว่าง "การเขียนนโยบายความปลอดภัย" กับ "การบังคับใช้นโยบายนั้นให้ครอบคลุมทุกเส้นทางที่ agent อาจเจอ" ซึ่งเป็นช่องว่างที่มักถูกมองข้าม
**ผู้เชี่ยวชาญด้าน AI:** การแยก ASSERT (หา coverage gap ในการประเมิน) ออกจาก ACS (บังคับใช้ policy จริง) เป็นสถาปัตยกรรมที่สมเหตุสมผล เพราะการทดสอบและการควบคุมมักต้องการเครื่องมือคนละแบบ ควรติดตามว่า Microsoft จะเปิด framework นี้เป็น open source หรือผูกกับ Azure AI เท่านั้น
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่สร้าง AI agent ที่แตะข้อมูลลูกค้าหรือระบบสำคัญควรนำแนวคิด ASSERT/ACS ไปเทียบกับ guardrail ที่ทีมมีอยู่ โดยเฉพาะการทดสอบ "failure path" ที่หลากหลายกว่าการทดสอบ policy แบบจุดเดียว

## 4. Apple — ปลดพนักงาน Siri/Vision Pro หลายร้อยตำแหน่ง ปรับทิศทางสู่ AI
**อาจารย์ (มหาวิทยาลัย):** ใช้เป็นกรณีศึกษาการปรับโครงสร้างองค์กรเพื่อรองรับการเปลี่ยนผ่านสู่ AI — เมื่อบริษัทใหญ่ตัดสินใจว่าจะลงทุนที่ไหนเพิ่ม มักต้องตัดที่อื่นควบคู่กันเสมอ
**ผู้เชี่ยวชาญด้าน AI:** การตัดทีม Vision Pro gaming และ immersive video ควบคู่กับการปรับทีม Siri สะท้อนว่า Apple กำลังจัดลำดับความสำคัญใหม่ให้ AI-powered features มาก่อนฮาร์ดแวร์ทดลองที่ยังไม่ประสบความสำเร็จเชิงพาณิชย์
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาที่ทำงานกับ Vision Pro SDK หรือ Siri integration ควรติดตามทิศทางนี้อย่างใกล้ชิด เพราะการปรับทีมภายในมักตามมาด้วยการเปลี่ยนแผน roadmap ของ API และเครื่องมือสำหรับนักพัฒนาภายนอกในไม่ช้า
