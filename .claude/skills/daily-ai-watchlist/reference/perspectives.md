# Perspectives — 2026-08-24 (watchlist)

## 1.1 Nvidia — 15%+ AI server price hike
**อาจารย์ (มหาวิทยาลัย):** เป็นตัวอย่างสอนเศรษฐศาสตร์ห่วงโซ่อุปทาน AI ได้ดี ต้นทุนหน่วยความจำ (HBM/DRAM) กำลังกลายเป็นคอขวดใหม่แทนที่จะเป็นแค่ GPU die เพียงอย่างเดียว
**ผู้เชี่ยวชาญด้าน AI:** การขึ้นราคาผูกกับแพลตฟอร์มรุ่นถัดไปอย่าง Vera Rubin และ Grace Blackwell ชี้ว่าต้นทุนการเทรน/รันโมเดลขนาดใหญ่จะเพิ่มขึ้นทั้งอุตสาหกรรม
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่วางแผนซื้อหรือเช่า capacity สำหรับ deliveries ปีหน้าควรล็อกราคา/สัญญาล่วงหน้าและประเมินงบประมาณ compute ใหม่ก่อนราคาปรับขึ้นจริง

## 1.2 Nvidia — DGX Station เกือบแสนดอลลาร์
**อาจารย์ (มหาวิทยาลัย):** สอนเรื่อง productization ของ enterprise AI hardware ที่ไล่ตั้งแต่ cloud instance ไปจนถึง on-prem workstation ราคาสูง
**ผู้เชี่ยวชาญด้าน AI:** DGX Station แบบ GB300 เป็นทางเลือกสำหรับองค์กรที่ต้องการ compute ระดับ data center แต่ควบคุมข้อมูลไว้ในองค์กรเอง (data sovereignty)
**โปรแกรมเมอร์มืออาชีพ:** ราคาระดับนี้เหมาะเฉพาะองค์กรที่มีงบสูงมาก ทีมทั่วไปควรเทียบ TCO กับการเช่า cloud GPU ก่อนตัดสินใจซื้อ

## 2. Alibaba — ระดมทุน $10 พันล้านลงทุน AI
**อาจารย์ (มหาวิทยาลัย):** เหมาะสอนเรื่องการระดมทุนผ่านตลาดทุนฮ่องกงเพื่อสนับสนุน capex ด้าน AI ของบริษัทเทคจีนภายใต้แรงกดดันด้านการแข่งขันกับสหรัฐฯ
**ผู้เชี่ยวชาญด้าน AI:** การที่ Livemint เทียบดีลนี้เป็นอันดับสามรองจาก Alphabet และ Intel สะท้อนว่าการระดมทุนขนาดใหญ่เพื่อ AI capex กลายเป็นบรรทัดฐานใหม่ของบริษัทเทคระดับโลก ไม่ใช่แค่สหรัฐฯ
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ Alibaba Cloud/Qwen ควรจับตาว่าเงินทุนก้อนนี้จะไปลง capacity หรือ R&D โมเดลใหม่ ซึ่งอาจกระทบ roadmap ผลิตภัณฑ์ที่ใช้อยู่

## 3. Amazon — คดีฟ้องร้องใช้คอนเทนต์ Twitch เทรน AI
**อาจารย์ (มหาวิทยาลัย):** กรณีนี้สอนเรื่อง consent และ data provenance ในการเทรนโมเดล AI ได้ตรงประเด็น โดยเฉพาะประเด็น opt-in กับ opt-out
**ผู้เชี่ยวชาญด้าน AI:** คำพูดของประธานฝ่ายผลิตภัณฑ์ Twitch ที่ว่า "ถ้าเป็น opt-in ไม่มีใครกดยอมรับหรอก" สะท้อนความตึงเครียดระหว่างการหาข้อมูลเทรนโมเดลกับสิทธิ์ของผู้สร้างคอนเทนต์อย่างตรงไปตรงมา
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่สร้างผลิตภัณฑ์ AI จากข้อมูลผู้ใช้ควรทบทวนนโยบาย consent ของตัวเองว่าเป็น opt-in หรือ opt-out และประเมินความเสี่ยงทางกฎหมายที่คล้ายกันล่วงหน้า

## 4. Alphabet (Waymo) — ชิป ASIC 5nm สำหรับรถโดยสารไร้คนขับ
**อาจารย์ (มหาวิทยาลัย):** เหมาะสอนเรื่อง vertical integration ในอุตสาหกรรม AI ที่บริษัทลงไปออกแบบฮาร์ดแวร์เองเพื่อลดต้นทุนและเพิ่มประสิทธิภาพ
**ผู้เชี่ยวชาญด้าน AI:** การประมวลผลข้อมูล sensor จำนวนมหาศาลก่อนถึง "สมอง" หลักของระบบขับขี่อัตโนมัติ เป็นแนวทางบีบ latency และต้นทุนพลังงานที่บริษัทรถยนต์ไร้คนขับรุ่นใหม่ต้องทำ
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ทำงานด้าน edge AI/robotics ควรศึกษาสถาปัตยกรรมแบบ custom ASIC pre-processing เป็นแนวทางลดภาระของโมเดลหลักเมื่อข้อมูล sensor มีปริมาณสูงมาก
