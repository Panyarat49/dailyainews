# Perspectives — 2026-07-21 (watchlist)

## 1. Alphabet — Google พัฒนาชิป "Frozen v2" เจาะจงรัน Gemini
**อาจารย์ (มหาวิทยาลัย):** แนวโน้มที่ lab ใหญ่ออกแบบฮาร์ดแวร์เฉพาะให้เข้ากับสถาปัตยกรรมโมเดลของตัวเอง (hardware/software co-design) เป็นทิศทางสำคัญที่ควรสอนคู่กับเนื้อหา computer architecture — มันกำลังกลายเป็นความได้เปรียบเชิงแข่งขันหลักของ AI lab ระดับบนสุดที่ควบคุมทั้ง stack
**ผู้เชี่ยวชาญด้าน AI:** ตัวเลขอ้างว่าเร็วกว่าเดิม 6-10 เท่าต่อการคำนวณเป็นตัวเลขที่น่าตื่นเต้นมาก แต่ยังเป็นเพียงรายงานจากแหล่งข่าวนิรนามผ่าน The Information ที่ Google ยังไม่ยืนยัน ต้องรอรายละเอียดสถาปัตยกรรมจริงก่อนประเมินความน่าเชื่อถือของตัวเลขนี้
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาที่ใช้ Gemini API ควรมองข่าวนี้เป็นสัญญาณว่าค่าใช้จ่ายต่อ token ของ Gemini อาจถูกลงมากในระยะ 2-3 ปีข้างหน้าเมื่อชิปเฉพาะทางเริ่มใช้งานจริงราวปี 2028 ควรวางแผน cost modeling ระยะยาวให้สอดคล้อง

## 2. Microsoft — Azure ขยายโครงสร้าง AI/HPC ด้วย AMD Helios "ระดับสเกลใหญ่"
**อาจารย์ (มหาวิทยาลัย):** ดีลนี้เป็นตัวอย่างชัดเจนของ multi-vendor strategy ในตลาด AI infrastructure — ไม่มี cloud รายใหญ่รายไหนยอมพึ่ง GPU vendor เดียวอีกต่อไป เหมาะเป็นกรณีศึกษาสอนเรื่อง supply chain diversification ในวิชา tech strategy
**ผู้เชี่ยวชาญด้าน AI:** การที่ Microsoft ประกาศเองผ่าน official blog (ไม่ใช่แค่ leak) สะท้อนความมั่นใจในดีลนี้ — MI455X และ Epyc Venice ถูกออกแบบมาชนกับ Nvidia โดยตรงในระดับ rack-scale ไม่ใช่แค่ชิปเดี่ยว แต่ยังไม่เปิดเผยตัวเลขปริมาณ compute ที่สั่งซื้อจริง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่รัน workload บน Azure AI ควรจับตา instance type ใหม่ที่ใช้ MI455X เพราะราคาต่อ FLOP อาจถูกกว่า H100/B200 อย่างมีนัยสำคัญ แต่ต้องทดสอบ compatibility ของ framework (ROCm เทียบกับ CUDA) ก่อน migrate workload จริง

## 3. Nvidia — AMD Helios ผงาดเป็นคู่แข่ง rack-scale รายแรก, Microsoft เข้าร่วมเป็นลูกค้า
**อาจารย์ (มหาวิทยาลัย):** กรณีนี้เหมาะสอนเรื่อง competitive dynamics ในตลาดผูกขาดบางส่วน (oligopoly) — เมื่อคู่แข่งเริ่มมีผลิตภัณฑ์ระดับเทียบเท่าและดึงลูกค้ารายใหญ่ได้ ตลาดที่เคย concentrate มากจะเริ่มกระจายตัว
**ผู้เชี่ยวชาญด้าน AI:** Helios คือความพยายามครั้งแรกของ AMD ที่ทำ rack-scale system เทียบชั้น Nvidia Vera Rubin ไม่ใช่แค่ระดับชิป GPU เดี่ยวเหมือนที่ผ่านมา การที่ Microsoft เข้าร่วมเป็นลูกค้าต่อจาก Meta, OpenAI และ Oracle เป็นสัญญาณว่า hyperscaler เริ่มกระจายความเสี่ยงด้าน supply จาก Nvidia อย่างจริงจัง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่วางแผน infrastructure ระยะยาวควรเริ่มประเมิน portability ของ workload ระหว่าง CUDA และ ROCm ตั้งแต่ตอนนี้ เพราะตลาด GPU/accelerator กำลังจะมีทางเลือกที่ใช้งานจริงได้มากขึ้นในอีก 1-2 ปีข้างหน้า

## 4. Alibaba — เปิดตัว Qwen 3.8 อ้างเป็นรองแค่ Claude Fable 5
**อาจารย์ (มหาวิทยาลัย):** การที่ Alibaba ประกาศ Qwen 3.8 ด้วยขนาดพารามิเตอร์เท่ากับ Kimi K3 ของ Moonshot AI พอดี (2.4 ล้านล้านพารามิเตอร์) สะท้อนว่าห้องแล็บจีนกำลังแข่งขันกันเองที่ scale เดียวกันเพื่อไล่ตาม frontier lab ตะวันตก เหมาะเป็นตัวอย่างสอนเรื่อง scaling race ในอุตสาหกรรม AI
**ผู้เชี่ยวชาญด้าน AI:** การอ้างว่าเป็นรองเพียง Claude Fable 5 โดยไม่เปิดเผยผลทดสอบเทียบมาตรฐานที่ตรวจสอบได้เป็นจุดที่ควรตั้งคำถามก่อนเชื่อ ต้องรอผู้ทดสอบอิสระยืนยัน แผนเปิด open-weight ในอนาคตอาจเป็นปัจจัยสำคัญกว่าตัวเลข benchmark ที่ยังพิสูจน์ไม่ได้
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้โมเดลเปิดจากจีนใน production ควรเตรียมทดสอบ Qwen 3.8 เทียบกับ Kimi K3 และ GLM เมื่อเปิด weight จริง เพราะการแข่งขันด้านราคาที่ดุเดือดขึ้นอาจทำให้ต้นทุน inference ถูกลงต่อเนื่อง แต่ควรตรวจสอบคุณภาพและ SLA ก่อนย้าย workload จริง
