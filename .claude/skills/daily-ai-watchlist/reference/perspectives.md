# Perspectives — 2026-08-03 (watchlist)

## 1. Apple — Global memory shortage hits the MacBook Air
**อาจารย์ (มหาวิทยาลัย):** เคสนี้สอนเรื่อง supply chain interdependency ได้ตรงจุด — ดีมานด์ชิปหน่วยความจำจากบริษัท AI ไปกระทบสินค้าอุปโภคทั่วไปอย่าง MacBook Air แสดงว่าผลกระทบของ AI ไม่ได้จำกัดอยู่แค่ตลาด GPU แต่ลามไปทั้ง memory supply chain ทั้งระบบ
**ผู้เชี่ยวชาญด้าน AI:** นี่คือสัญญาณว่า capacity crunch ของ HBM/DRAM สำหรับ training cluster เริ่มล้นไปกระทบ consumer-grade memory แล้ว น่าสังเกตว่า Apple เองก็เป็นผู้เล่นในสมรภูมิ AI capex เดียวกัน แต่กลับเป็นฝ่ายรับผลกระทบจากดีมานด์ของคู่แข่ง
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่วางแผนซื้อฮาร์ดแวร์สำหรับ dev/local-inference ควรเร่งจัดซื้อล่วงหน้า เพราะราคาและ lead time มีแนวโน้มแย่ลงก่อนจะดีขึ้น และ Apple เองก็ต้องขึ้นราคาสินค้าเพื่อรับมือ

## 2. Amazon — AWS โต 37% ยกระดับ AI capex เป็น 2.2 แสนล้านดอลล์
**อาจารย์ (มหาวิทยาลัย):** ตัวเลข backlog ที่พุ่งขึ้น 1.32 แสนล้านดอลล์ในไตรมาสเดียวเป็นตัวชี้วัดดีมานด์ล่วงหน้าที่ดีกว่าตัวเลขรายได้ปัจจุบัน — เหมาะใช้สอนนักเรียนเรื่องการอ่าน forward-looking indicator ในธุรกิจ infrastructure
**ผู้เชี่ยวชาญด้าน AI:** ที่น่าสนใจคือ Amazon ระบุชัดว่าต้นทุนหน่วยความจำ HBM เป็นตัวขับดัน capex ที่เพิ่มขึ้น ไม่ใช่แค่ GPU เอง สะท้อนว่า cost structure ของ AI infrastructure กำลังซับซ้อนขึ้นเรื่อย ๆ และ chip ของ Amazon เอง (Trainium) ก็ทำรายได้เกิน 2.5 หมื่นล้านดอลล์ต่อปีแล้ว
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ AWS Bedrock/Trainium ควรติดตามว่าการเพิ่ม capacity นี้จะแปลงเป็น availability และราคาที่ดีขึ้นสำหรับ inference workload เมื่อใด โดยเฉพาะช่วงที่ตลาดยังขาดแคลน compute อยู่ทั่วไป

## 3. Meta — กระแสเงินสดร่วงเหลือ $784M จากการทุ่ม AI capex
**อาจารย์ (มหาวิทยาลัย):** กรณี Meta เป็นตัวอย่างชัดเจนของ trade-off ระหว่างการลงทุนระยะยาวกับสุขภาพการเงินระยะสั้น — free cash flow ที่ร่วงจาก 8.55 พันล้านเหลือ 784 ล้านดอลล์ในปีเดียวคือบทเรียนเรื่อง capital allocation risk ที่ควรใช้สอนในวิชาการเงินองค์กร
**ผู้เชี่ยวชาญด้าน AI:** การที่ Meta เพิ่ม capex floor เป็น 1.3 แสนล้านดอลล์ท่ามกลาง cash flow ที่ทรุดตัว สะท้อนความเชื่อมั่นสูงมากว่าการลงทุนนี้จะคุ้มค่าระยะยาว แต่ตลาดเริ่มตั้งคำถามว่าจุดคุ้มทุนของ AI infrastructure ระดับนี้จะมาถึงเมื่อไร
**โปรแกรมเมอร์มืออาชีพ:** นักลงทุนและทีมงานที่พึ่งพา Meta AI/Llama ควรจับตาสัญญาณการปรับลด scope หรือ timeline หากแรงกดดันด้าน cash flow ยังคงอยู่ต่อเนื่องในไตรมาสถัดไป

## 4. Nvidia — เจรจาค้ำประกันเงินกู้ $250B ให้ OpenAI สร้างดาต้าเซ็นเตอร์
**อาจารย์ (มหาวิทยาลัย):** ดีลนี้เป็นกรณีศึกษาเรื่อง circular financing ในอุตสาหกรรม AI — Nvidia ค้ำประกันหนี้ให้ลูกค้าซื้อชิปตัวเอง คำถามเชิงวิพากษ์ที่ควรถกคือความเสี่ยงเชิงระบบหากดีมานด์ AI ชะลอตัวกะทันหัน
**ผู้เชี่ยวชาญด้าน AI:** ขนาด 10 กิกะวัตต์สำหรับดาต้าเซ็นเตอร์เดียวคือระดับที่ไม่เคยมีมาก่อน และการที่ OpenAI ต้องการควบคุมโครงสร้างพื้นฐานเองแทนที่จะเช่าจาก Microsoft/Amazon/Oracle สะท้อนความต้องการอิสระด้าน compute ในระยะยาว
**โปรแกรมเมอร์มืออาชีพ:** ดีลลักษณะนี้การันตีดีมานด์ชิป Nvidia ไปอีกหลายปี ทีมที่วางแผน roadmap ระยะยาวบน GPU Nvidia ควรมองเป็นสัญญาณบวกต่อ supply แต่ก็ควรระวังความเสี่ยงด้าน concentration หากพึ่งพา ecosystem เดียวมากเกินไป

## 5. Microsoft — Azure ทะลุ 1 แสนล้านดอลล์ต่อปี Copilot ผู้ใช้จ่ายเงินเพิ่มเป็น 30 ล้าน
**อาจารย์ (มหาวิทยาลัย):** การที่ Azure โตเร่งขึ้นเป็น 43% แม้ฐานรายได้ใหญ่ระดับแสนล้านแล้ว ผิดกับกฎ "law of large numbers" ทั่วไปในธุรกิจเทคโนโลยี เป็นเคสที่น่าสอนเรื่อง exception ของการเติบโตในยุค AI infrastructure boom
**ผู้เชี่ยวชาญด้าน AI:** ตัวเลข Copilot ที่ paid seats เพิ่มเป็นสองเท่าในเวลาไม่กี่เดือนสำคัญกว่าตัวเลข Azure เสียอีก เพราะแสดงว่า monetization ของ AI ระดับ end-user เริ่มเป็นรูปเป็นร่างจริง ไม่ใช่แค่ hype หรือ pilot project
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ GitHub Copilot (ตอนนี้ 50 ล้านผู้ใช้) หรือวางแผนย้ายไป Azure AI ควรติดตาม roadmap การลงทุน capex ของ Microsoft ต่อเนื่อง เพราะ growth ระดับนี้มักตามมาด้วยการอัปเกรด capacity และ pricing tier ใหม่
