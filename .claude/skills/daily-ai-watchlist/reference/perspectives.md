# Perspectives — 2026-09-27 (watchlist)

## 1. Microsoft — Copilot รวมแอปผู้ใช้ทั่วไป/องค์กร เพิ่ม Code และ Autopilot
**อาจารย์ (มหาวิทยาลัย):** เหมาะเป็นกรณีศึกษากลยุทธ์ธุรกิจ — การถอยจากตลาด "personal AI companion" ที่แข่งขันดุเดือดไปโฟกัสตลาดองค์กรที่ทำกำไรชัดเจนกว่า สะท้อนหลักการ positioning ที่นักศึกษา MBA ควรวิเคราะห์
**ผู้เชี่ยวชาญด้าน AI:** การรวม Code tab (ฐาน GitHub Copilot) กับ Autopilot agent เข้าด้วยกันในแอปเดียว เป็นความพยายามลด friction ระหว่าง "การเขียนโค้ด" กับ "การมอบหมายงานให้ agent ทำแทน" ซึ่งเป็นทิศทางที่คู่แข่งอย่าง Anthropic ก็กำลังผลักดันเช่นกัน
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ Microsoft 365 อยู่แล้วควรประเมิน Autopilot tab ว่าคุ้มค่ากับโมเดลคิดเงินตามการใช้งาน (usage-based) หรือไม่ เทียบกับ subscription คงที่แบบเดิม ก่อนขยายการใช้งานทั้งองค์กร

## 2. Alibaba — เปิดตัวชิป Zhenwu V900 และแผนโมเดล Qwen 10 ล้านล้านพารามิเตอร์
**อาจารย์ (มหาวิทยาลัย):** ตัวอย่างชัดเจนของ "compute sovereignty" — บริษัทจีนพัฒนาชิปเองเพื่อลดการพึ่งพา Nvidia ท่ามกลางมาตรการควบคุมการส่งออกของสหรัฐฯ เหมาะสอนคู่กับหัวข้อภูมิรัฐศาสตร์เทคโนโลยี
**ผู้เชี่ยวชาญด้าน AI:** การขยับจาก Qwen3.8-Max (2.4T parameters) ไปสู่โมเดลระดับ 5-10 ล้านล้านพารามิเตอร์เป็นการก้าวกระโดดใหญ่ ต้องจับตาว่าคุณภาพเพิ่มขึ้นสมส่วนกับขนาดหรือไม่ หรือเป็นเพียงการไล่ตามตัวเลขเพื่อการตลาด
**โปรแกรมเมอร์มืออาชีพ:** ชิป Zhenwu V900 ที่รองรับคลัสเตอร์ 500,000 การ์ด เป็นสัญญาณว่า Alibaba Cloud จะมีกำลัง compute ราคาถูกลงให้ลูกค้าองค์กรในเอเชียเลือกใช้แทน GPU ของ Nvidia มากขึ้น ควรติดตามราคาและ SDK support เมื่อเปิดใช้จริงต้นปี 2027

## 3. Apple — เปิดตัว Siri AI เวอร์ชันใหม่พร้อมอัปเดตซอฟต์แวร์ครั้งใหญ่
**อาจารย์ (มหาวิทยาลัย):** ควรใช้สอนเรื่อง "AI ที่เข้าใจบริบทส่วนตัว" (personal-context AI) และประเด็นความเป็นส่วนตัวที่มาพร้อมกัน เพราะ Siri AI ใหม่เข้าถึงข้อความ อีเมล และรูปภาพของผู้ใช้โดยตรง
**ผู้เชี่ยวชาญด้าน AI:** การที่ Apple รอเกือบทั้งปีกว่าจะปล่อย Siri AI เวอร์ชันเต็มหลังบีตา สะท้อนความยากของการทำ on-device + cloud hybrid AI ให้แม่นยำและปลอดภัยพอสำหรับข้อมูลส่วนตัวระดับนี้
**โปรแกรมเมอร์มืออาชีพ:** นักพัฒนาแอป iOS ควรเริ่มทดสอบ App Intents และ system-wide action ใหม่ที่ Siri AI เปิดให้ เพราะจะกลายเป็นช่องทางหลักที่ผู้ใช้เข้าถึงฟีเจอร์แอปผ่านคำสั่งเสียง/context แทนการเปิดแอปตรงๆ มากขึ้น

## 4. AMD — ทะลุมูลค่าตลาด 1 ล้านล้านดอลลาร์จากแรงหนุน AI
**อาจารย์ (มหาวิทยาลัย):** ใช้เป็นตัวอย่างสอนเรื่อง valuation ที่ขับเคลื่อนด้วย narrative — การเติบโตของรายได้ data center 107% เป็นตัวเลขจริง แต่ราคาหุ้นที่พุ่ง 187% ในปีเดียวสะท้อนความคาดหวังต่ออนาคตด้วย ไม่ใช่แค่ผลประกอบการปัจจุบัน
**ผู้เชี่ยวชาญด้าน AI:** AMD ยังตามหลัง Nvidia ราว 5.4 เท่าในมูลค่าตลาด บ่งชี้ว่าตลาดยังมองว่า CUDA ecosystem ของ Nvidia เป็นกำแพงที่แข็งแกร่งกว่า แม้ Instinct GPU จะมีสเปกแข่งขันได้ในหลายมิติ
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่พิจารณาย้ายจาก CUDA ไป ROCm (AMD) เพื่อลดต้นทุน ควรจับตาว่าการเติบโตของรายได้ data center นี้แปลเป็นการลงทุนด้าน software tooling/compatibility ที่ลด friction การย้ายจริงหรือไม่
