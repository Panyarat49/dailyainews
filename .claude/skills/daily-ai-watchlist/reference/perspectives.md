# Perspectives — 2026-09-09 (watchlist)

## 1. Meta Platforms — Muse personal AI agent debut
**อาจารย์ (มหาวิทยาลัย):** คำถามเรื่องความไว้วางใจ (trust) จะสำคัญกว่าความสามารถทางเทคนิคของ agent — ยิ่งขอสิทธิ์เข้าถึงข้อมูลส่วนตัวมากเท่าไหร่ ภาระพิสูจน์ความปลอดภัยก็ยิ่งสูงตาม
**ผู้เชี่ยวชาญด้าน AI:** การให้ agent เข้าถึงอีเมล ปฏิทิน การชำระเงิน และข้อมูลสุขภาพพร้อมกัน คือการขยาย attack surface อย่างมีนัยสำคัญ ไม่ใช่แค่ฟีเจอร์ใหม่
**โปรแกรมเมอร์มืออาชีพ:** ผู้ที่จะทดลองหรือ integrate agent ลักษณะนี้ควร scope permission ให้แคบที่สุดก่อน แล้วค่อยขยาย พร้อมมี audit log ตรวจสอบย้อนกลับได้ทุก action

## 2. Alphabet — Google Cloud + Accenture deepen Gemini Enterprise alliance
**อาจารย์ (มหาวิทยาลัย):** สะท้อนภาพรวมตลาดว่า "การ deploy" ไม่ใช่ "การมีโมเดล" คือคอขวดจริงขององค์กรขนาดใหญ่ในการใช้ agentic AI
**ผู้เชี่ยวชาญด้าน AI:** การพึ่ง forward-deployed engineers เป็นการยอมรับโดยปริยายว่า generic enterprise AI tooling ยังต้องพึ่งทีมมนุษย์ปรับแต่งเฉพาะหน้างานอยู่มาก
**โปรแกรมเมอร์มืออาชีพ:** องค์กรที่ประเมิน Gemini Enterprise ควรถามหา case study ที่วัดผลได้จริงจากดีลนี้ ไม่ใช่แค่ตัวเลข commitment ทางการตลาด

## 3. Microsoft — sued by Seattle Times and Newsday over AI training data
**อาจารย์ (มหาวิทยาลัย):** เป็นกรณีศึกษาต่อเนื่องเรื่องขอบเขต "fair use" ในการฝึกโมเดล AI ด้วยเนื้อหาข่าวที่มีลิขสิทธิ์ — คำตัดสินสะสมจากคดีเหล่านี้จะกำหนดกติกาของอุตสาหกรรมทั้งหมด
**ผู้เชี่ยวชาญด้าน AI:** ข้อกล่าวหาเรื่องการ "scrape" เนื้อหาแบบเลี่ยงระบบ paywall เป็นประเด็นทางเทคนิคที่ต่างจากคดีลิขสิทธิ์ทั่วไป เพราะพาดพิงถึงวิธีการเก็บข้อมูลฝึกโมเดลโดยตรง ไม่ใช่แค่การใช้งานผลลัพธ์
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่สร้างระบบ web crawling หรือ RAG pipeline ควรตรวจสอบ robots.txt และเงื่อนไขการเข้าถึงเนื้อหาที่มี paywall อย่างเคร่งครัดขึ้น เพราะความเสี่ยงทางกฎหมายกำลังเพิ่มขึ้นเรื่อยๆ

## 4. TSMC — leads 12-inch photomask push with ASML, Samsung, Intel
**อาจารย์ (มหาวิทยาลัย):** เทียบได้กับการเปลี่ยนจาก wafer ขนาด 200mm ไปเป็น 300mm ในอดีต เป็นตัวอย่างที่ดีว่าการเปลี่ยนแปลงมาตรฐานอุตสาหกรรมทั้งระบบใช้เวลาเป็นทศวรรษ
**ผู้เชี่ยวชาญด้าน AI:** ปัญหาที่แท้จริงคือ die ของชิป AI ยุคใหม่ใหญ่เกินกว่าขนาด exposure field ของ mask แบบเดิม บังคับให้ต้องต่อหลาย field เข้าด้วยกันหรือใช้ chiplet ซึ่งกระทบต้นทุนและ yield โดยตรง
**โปรแกรมเมอร์มืออาชีพ:** เป็นข่าวระยะยาว (pilot line ปี 2031, การผลิตจริงปี 2033) ที่ไม่กระทบ roadmap การพัฒนา software ระยะสั้น แต่ทีมที่วางแผน capacity ระยะยาวควรรู้ไว้ว่าคอขวดด้าน lithography นี้จะกระทบราคา/ปริมาณชิป AI ในอนาคต
