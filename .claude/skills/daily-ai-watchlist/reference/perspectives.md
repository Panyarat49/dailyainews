# Perspectives — 2026-09-06 (watchlist)

## 1. Nvidia (NVDA · Tier 1) — ทุ่ม 3.5 พันล้านดอลลาร์ลงทุนใน MediaTek
**อาจารย์ (มหาวิทยาลัย):** ดีลนี้เหมาะสอนเรื่อง vertical ecosystem lock-in — Nvidia ไม่ได้ขาย GPU อย่างเดียวอีกต่อไป แต่ลงทุนในซัพพลายเชนเพื่อให้ชิปคู่แข่ง/พันธมิตรต้องพึ่ง NVLink Fusion ของตัวเอง
**ผู้เชี่ยวชาญด้าน AI:** การที่ไฮเปอร์สเกลเลอร์เร่งสร้างชิปของตัวเอง (Amazon, Google, Microsoft, OpenAI, Anthropic) ทำให้ Nvidia ต้องเปลี่ยนกลยุทธ์จาก "ขายชิปให้ทุกคน" เป็น "ให้ระบบนิเวศเชื่อมกับ Nvidia ไม่ว่าใครจะผลิตชิปเอง" ซึ่งเป็นการป้องกันความเสี่ยงระยะยาวที่ชาญฉลาด
**โปรแกรมเมอร์มืออาชีพ:** ทีม infra ที่วางแผนใช้ ASIC แบบกำหนดเองควรติดตาม NVLink Fusion spec เพราะอาจกลายเป็นมาตรฐานเชื่อมต่อ de facto ระหว่างชิปต่างค่ายในศูนย์ข้อมูล AI ยุคถัดไป

## 2. Tesla (TSLA · Tier 1) — เปิดตัว Cybercab ในออสติน
**อาจารย์ (มหาวิทยาลัย):** เคสนี้ใช้สอนความแตกต่างระหว่าง "product demo" กับ "commercial scale" ได้ดี เพราะงานเปิดตัวเป็นแบบปิด จำกัดเฉพาะแขกและพนักงาน ยังไม่ใช่การพิสูจน์ตลาดจริง
**ผู้เชี่ยวชาญด้าน AI:** Cybercab ใช้ชิป AI5 และแพลตฟอร์ม FSD ร่วมกับ Optimus ซึ่งเป็นการยืนยันว่า Tesla วางกลยุทธ์ AI แบบ shared-stack ระหว่างหุ่นยนต์และยานยนต์ขับเคลื่อนอัตโนมัติ ไม่ใช่โปรเจกต์แยกกัน
**โปรแกรมเมอร์มืออาชีพ:** ความสำเร็จหรือความล้มเหลวของการสเกล fleet จาก 10 เป็น 1,000 คันจะเป็นตัวชี้วัดสำคัญของความพร้อมจริงของซอฟต์แวร์ FSD แบบไม่มีผู้ดูแลความปลอดภัย ซึ่งทีมที่ทำงานด้าน autonomous system ควรติดตามอัตราการแทรกแซงระยะไกล (remote intervention rate)

## 3. Microsoft (MSFT · Tier 1) — นำ GPT-6 Astra และ MAI-Transcribe-2 ขึ้น Azure AI Foundry
**อาจารย์ (มหาวิทยาลัย):** เปรียบเทียบสองผลิตภัณฑ์นี้ได้ดีในแง่กลยุทธ์แพลตฟอร์ม — Microsoft ทั้งเป็น "ผู้จัดจำหน่าย" โมเดลของ OpenAI และ "ผู้พัฒนา" โมเดลของตัวเอง (MAI) คู่ขนานกัน
**ผู้เชี่ยวชาญด้าน AI:** การที่ MAI-Transcribe-2 เร็วกว่า GPT-Transcribe ถึง 10 เท่าและถูกกว่าเดิม 72% แสดงว่า Microsoft กำลังเก็บเกี่ยว in-house model สำหรับงานเฉพาะทาง (transcription) แทนที่จะพึ่ง OpenAI ทุกงาน เป็นการกระจายความเสี่ยงด้าน vendor
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ Azure อยู่แล้วควรทดสอบ MAI-Transcribe-2 สำหรับงาน transcription แทน GPT-Transcribe ทันทีเพื่อลดต้นทุนกว่า 70% และเก็บ GPT-6 Astra ไว้เฉพาะงานที่ต้องการ reasoning ระดับสูงเท่านั้น

## 4. Amazon (AMZN · Tier 1) — Anthropic เปิดตัว Claude Fable 5.1 และ Mythos 5.1
**อาจารย์ (มหาวิทยาลัย):** เคสนี้สอนเรื่องความสัมพันธ์แบบ strategic investor ระหว่าง Amazon กับ Anthropic — AWS ไม่ได้เป็นแค่ผู้ให้บริการคลาวด์ แต่มีผลประโยชน์โดยตรงกับความสำเร็จของโมเดล Claude ผ่าน Bedrock
**ผู้เชี่ยวชาญด้าน AI:** การลดต้นทุนงาน agentic ลง 45% ของ Fable 5.1 มีนัยสำคัญต่อ AWS โดยตรง เพราะทำให้ลูกค้า Bedrock ใช้งานหนักขึ้นได้โดยไม่เพิ่มค่าใช้จ่ายตามสัดส่วน ซึ่งหนุนทั้งรายได้ AWS และความสามารถแข่งขันกับ Azure/GCP
**โปรแกรมเมอร์มืออาชีพ:** ทีมที่ใช้ Claude ผ่าน Bedrock ควรตรวจสอบว่า Fable 5.1/Mythos 5.1 พร้อมใช้งานบน AWS แล้วหรือยัง และประเมินการย้ายจาก Fable 5 เพื่อรับส่วนลด cache-read ทันที

## 5. Alphabet (GOOGL · Tier 1) — Gemini 3.8 Flash เทียบชั้น Opus 5 ด้านโค้ดดิ้ง
**อาจารย์ (มหาวิทยาลัย):** ใช้สอนการอ่านผลทดสอบ "internal benchmark" อย่างมีวิจารณญาณ เพราะ Google เป็นทั้งผู้พัฒนาและผู้ประเมินผลในกรณีนี้
**ผู้เชี่ยวชาญด้าน AI:** การที่ Flash-tier ไล่ทัน flagship ของคู่แข่งในงานจริงสะท้อนว่าโมเดลราคาถูกเริ่มลดช่องว่างด้านคุณภาพ ขณะที่ความได้เปรียบด้าน latency และอัตราการหลอนต่ำอาจสำคัญกว่าความสามารถดิบสำหรับงาน production
**โปรแกรมเมอร์มืออาชีพ:** ราคาที่ถูกกว่ารุ่น flagship มาก ทำให้ Gemini 3.8 Flash เหมาะเป็นค่าเริ่มต้นสำหรับงาน agentic coding ปริมาณสูง ทีมควรทดสอบเทียบ cost-per-task กับ Fable 5.1 ก่อนตัดสินใจเปลี่ยนสแตกหลัก
