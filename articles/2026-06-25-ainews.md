### 4. Mistral เปิดตัว OCR 4 — Document Intelligence ที่ deploy ใน Infrastructure ตัวเองได้ — [VentureBeat](https://venturebeat.com/data/mistral-launches-ocr-4-turning-document-extraction-into-a-full-enterprise-ai-play)

**Mistral AI** เปิดตัว **OCR 4** โมเดล document intelligence รุ่นที่สี่ที่ก้าวไกลกว่าการแยก text ธรรมดา ไปสู่การสร้าง "structured representation" ของเอกสารทั้งหมด พร้อม **bounding boxes, block-type classification และ per-word confidence scores** รองรับ 170 ภาษาใน 10 language groups และรับ PDF, DOC, PPT และ OpenDocument formats จุดขายหลักคือสามารถ deploy เป็น **single container บน infrastructure ขององค์กรเอง** โดยไม่ต้องส่งข้อมูลออกสู่ cloud APIs ที่อยู่ในเขตอำนาจศาลสหรัฐฯ — ตอบโจทย์ regulated industries ในยุโรปและเอเชียที่มีข้อกำหนด data residency ราคาเริ่มต้น $4 ต่อ 1,000 หน้า (หรือ $2 ต่อ 1,000 หน้าผ่าน batch API) พร้อมวางจำหน่ายทันทีผ่าน Mistral API, Amazon SageMaker และ Microsoft Foundry

### 5. Shopify สร้าง AI Stack ที่ไม่ยึดติด Provider ใด — บทเรียนจาก Claude Fable 5 Shutdown — [VentureBeat](https://venturebeat.com/orchestration/how-shopify-built-an-ai-stack-that-doesnt-care-which-models-survive)

Shopify เปิดเผยว่าได้สร้าง **LLM proxy** ที่ให้ engineers ทุกคนในบริษัทเข้าถึง AI providers หลายรายพร้อม automatic failover ในเวลาจริง Farhan Thawar หัวหน้า engineering เล่าว่าเมื่อ **Claude Fable 5 ถูกปิด** engineers ไม่ต้องตื่นตระหนก เพราะ proxy ย้าย workload ไปยัง Claude Opus หรือ GPT 5.5 โดยอัตโนมัติโดยไม่ขัดจังหวะงาน Shopify ซื้อ tokens แบบ bulk และทุก user เชื่อมต่อผ่าน proxy ซึ่งให้ reporting, failover และ visibility ครบถ้วน Thawar แนะนำว่า enterprise ควรสร้าง backup plan ที่ solid โดยเฉพาะองค์กรที่ยังผูกติดกับ provider เดียว และ distillation — การสร้าง small, specialized model จาก large teacher model — เป็น strategy ลดต้นทุนระยะยาวอีกแนวทาง
