### 1. Trump ยกเลิกข้อจำกัดส่งออกโมเดล Mythos และ Fable ของ Anthropic — [TechCrunch](https://techcrunch.com/2026/06/30/trump-drops-restrictions-on-anthropics-mythos-and-fable-models/)

กระทรวงพาณิชย์สหรัฐฯ ถอนคำสั่งควบคุมการส่งออก (export control) ที่บังคับใช้กับโมเดล **Mythos** และ **Fable** ของ Anthropic ตั้งแต่วันที่ 12 มิถุนายน ซึ่งเคยตัดการเข้าถึงโมเดลทั้งสองสำหรับผู้ใช้นอกสหรัฐฯ โดยสิ้นเชิง เพราะการปฏิบัติตามกฎในระดับ scale ทำไม่ได้จริง รัฐมนตรีพาณิชย์ Howard Lutnick ระบุว่า Anthropic ตกลงจะตรวจจับและแก้ไขความเสี่ยงด้านความปลอดภัยเชิงรุก ทำงานร่วมกับรัฐบาลเรื่อง protocol และมาตรฐานการปล่อยโมเดลในอนาคต พร้อมแจ้งกิจกรรมที่เป็นอันตรายให้รัฐบาลทราบ Anthropic เริ่มคืนการเข้าถึงทั่วโลกตั้งแต่วันที่ 1 กรกฎาคม

เหตุการณ์นี้คือตัวอย่างชั้นดีของ policy whiplash ในการกำกับดูแล AI — คำสั่งแบนที่ถอนภายในไม่กี่สัปดาห์สะท้อนว่ากรอบกฎหมายยังตามจังหวะการพัฒนาโมเดล frontier ไม่ทัน และเงื่อนไขที่ Anthropic ต้องยอมรับก็เป็นสิ่งที่บริษัทประกาศทำอยู่แล้วก่อนมีคำสั่งแบน ทำให้ผู้เชี่ยวชาญ security มองว่าคำสั่งเดิมเป็นเรื่อง leverage ทางการเมืองมากกว่าความปลอดภัยจริง ทีมที่ใช้ Fable 5/Mythos ผ่าน API นอกสหรัฐฯ ควรตรวจสอบสถานะ access คืนทันที แต่ก็ควรจำไว้เป็นบทเรียนว่าการพึ่งพาโมเดลเดียวจากผู้ให้บริการรายเดียวมีความเสี่ยงเชิงนโยบายที่ควบคุมไม่ได้

### 2. Red Team เปลี่ยน Claude Desktop ให้เป็น "Double Agent" จนได้ RCE เต็มรูปแบบ — [The Register](https://www.theregister.com/security/2026/07/01/red-teamers-turned-claude-desktop-into-a-double-agent-to-do-their-evil-bidding/5264692)

ทีม red team จาก **Pentera Labs** สาธิตการโจมตีที่เริ่มจากการ hijack กล่องอีเมลบนแพลตฟอร์มรวมศูนย์ inbox ของบุคคลที่สาม แล้วใช้กล่องอีเมลที่ยึดได้นั้นเป็นช่องทางเข้าถึงบัญชี Claude ของเหยื่อ ก่อนจะยกระดับไปจนได้ **remote code execution เต็มรูปแบบ** บนเครื่องของนักพัฒนาผ่าน Claude Desktop โดยหัวหน้าทีม Dvir Avraham เผยว่าการโจมตีอาศัย "ความไว้ใจ" ที่ผู้ใช้มีต่อ AI assistant เป็นเครื่องมือหลอกเหยื่อโดยที่เหยื่อไม่ทันสังเกต

สิ่งที่น่ากังวลที่สุดคือ attacker ไม่ต้องเจาะ Claude โดยตรง แค่ hijack integration ภายนอกที่เชื่อมต่ออยู่ก็พอ แสดงว่า chain-of-trust ระหว่าง agent กับระบบภายนอกคือจุดอ่อนที่แท้จริง ไม่ใช่ตัวโมเดล และ mitigation ต้องอยู่ที่ layer การเชื่อมต่อ ไม่ใช่แค่ guardrail ของ LLM งานวิจัยนี้ควรเป็นบทเรียนเรื่อง trust boundary ในระบบ agentic AI — ทีมที่ deploy Claude Desktop หรือ agentic tool ใดๆ ที่มี local code-execution ควรตรวจสอบทุก integration ที่ agent เข้าถึงได้ทันที และเพิ่ม human-in-the-loop confirmation ก่อนรัน command ที่มีผลกระทบสูง
