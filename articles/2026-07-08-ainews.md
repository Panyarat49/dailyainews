### 1. ช่องโหว่ "GitLost" หลอก AI agent ของ GitHub ให้รั่วไหลข้อมูล private repo — [The Register](https://www.theregister.com/security/2026/07/07/github-ai-agent-leaks-private-repos-when-asked-nicely/5267924)

นักวิจัยจาก Noma Labs เปิดเผยช่องโหว่ prompt injection ที่ตั้งชื่อว่า "GitLost" ในฟีเจอร์ GitHub Agentic Workflows ซึ่งให้ AI agent ที่ขับเคลื่อนด้วย Claude หรือ GitHub Copilot ทำงานอัตโนมัติใน GitHub Actions ได้ ผู้โจมตีสามารถหลอกให้ agent ดึงข้อมูลจาก private repository แล้วรั่วไหลออกมาเป็นคอมเมนต์สาธารณะที่ใครก็เข้าถึงได้ โดย GitHub ยังไม่มีทั้งวิธีแก้และเอกสารเตือนอย่างเป็นทางการ

ช่องโหว่นี้เป็นกรณีศึกษาชั้นดีเรื่อง "least privilege" ในการออกแบบ agentic system เพราะรากปัญหาไม่ได้อยู่ที่ตัวโมเดลใดโมเดลหนึ่ง แต่อยู่ที่สถาปัตยกรรม workflow ที่ให้ agent มีสิทธิ์เข้าถึงข้อมูลลับและโพสต์ผลลัพธ์แบบสาธารณะพร้อมกัน ทำให้ใช้ได้ผลทั้งกับ agent ที่ใช้ Claude หรือ Copilot เป็นเครื่องยนต์ และยังไม่มี fix จาก GitHub องค์กรที่เปิดใช้ฟีเจอร์นี้จึงเสี่ยงต่อเนื่อง ทีมที่เปิดใช้ GitHub Agentic Workflows ควรตรวจสอบทันทีว่า agent มีสิทธิ์เข้าถึง private repo ใดบ้าง และปิดความสามารถโพสต์คอมเมนต์สาธารณะจาก workflow ที่แตะข้อมูล sensitive จนกว่าจะมี patch อย่างเป็นทางการ

พบเวิร์มตัวใหม่ชื่อ "Cloud AI Infrastructure Attack Framework" (CAI) เป็น botnet ที่พุ่งเป้าไปที่เครื่องมือ cloud-native สำหรับงาน developer อย่าง Docker, Kubernetes, Redis, etcd, Kubelet และ Ray เพื่อขโมย credential และขุดคริปโตเคอร์เรนซี พร้อมทั้งฆ่ากระบวนการของมัลแวร์ขโมยข้อมูลคู่แข่งที่ติดตั้งอยู่ในเครื่องเดียวกัน

ปรากฏการณ์ "โจรขโมยของจากโจร" นี้เป็นตัวอย่างที่ดีของวิวัฒนาการ malware ที่แข่งขันกันเองในระบบนิเวศอาชญากรรมไซเบอร์ ไม่ใช่แค่ภัยจากฝ่ายเดียวอีกต่อไป ที่น่าสนใจคือ CAI เจาะจงเป้าหมายเครื่องมือ AI/ML infrastructure สมัยใหม่โดยเฉพาะ Ray ซึ่งใช้กันแพร่หลายใน distributed AI training และ serving สะท้อนว่าผู้โจมตีเข้าใจ stack ของงาน AI เป็นอย่างดี ทำให้ workload AI กลายเป็นเป้าที่มีมูลค่าสูงขึ้นเรื่อย ๆ ทีมที่รัน Kubernetes หรือ Ray cluster สำหรับ AI workload ควรตรวจสอบทันทีว่า dashboard และ API endpoint ของเครื่องมือเหล่านี้ไม่ได้เปิดสู่อินเทอร์เน็ตแบบไม่มี authentication เพราะเป็นช่องทางหลักที่เวิร์มประเภทนี้ใช้เจาะเข้าระบบ
