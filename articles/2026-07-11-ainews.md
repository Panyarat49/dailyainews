### 4. Anthropic เผยงานวิจัยใหม่ อ้างว่า "อ่านความคิด" ของ Claude ได้ผ่านโครงสร้าง global workspace — [Anthropic](https://www.anthropic.com/research/global-workspace)

Anthropic เผยแพร่งานวิจัยด้าน interpretability ที่พบหลักฐานของ "J-space" — ชุด representation ภายในขนาดเล็กที่ทำหน้าที่คล้าย workspace ร่วมสำหรับการให้เหตุผลที่ "อธิบายได้และปรับทิศทางได้" ภายในโมเดล Claude โดยใช้เทคนิคที่เรียกว่า J-lens ในการอ่านรูปแบบกิจกรรมภายในนี้ ([Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-says-it-can-read-claudes-thoughts-as-detailed-in-new-research-paper-models-observed-to-have-a-global-workspace-revealing-more-of-what-makes-llms-tick) รายงานประเด็นเดียวกัน) Anthropic ระบุชัดว่านี่เป็นความก้าวหน้าด้าน interpretability ไม่ใช่หลักฐานว่าโมเดลมีจิตสำนึก

งานวิจัยนี้เชื่อมทฤษฎี Global Workspace จากประสาทวิทยาศาสตร์เข้ากับสถาปัตยกรรม LLM เป็นตัวอย่างที่ดีสำหรับสอนแนวคิด interpretability และเตือนไม่ให้สรุปเกินหลักฐานเพียงเพราะพบโครงสร้างภายในที่คล้ายทฤษฎีมนุษย์ ในทางเทคนิค J-lens ชี้ให้เห็นว่าการให้เหตุผลบางส่วนของ Claude เกิดขึ้นใน representation ที่อ่านได้จริง ไม่ใช่แค่ black box อีกต่อไป และอาจกลายเป็นเครื่องมือ monitoring ในอนาคต เช่น ตรวจจับ hidden goal หรือ prompt injection ก่อนโมเดลตอบ ทีม safety/security ควรติดตามว่า Anthropic จะเปิด tooling ส่วนนี้ให้บุคคลภายนอกใช้เมื่อไร
