### 1. AMD เปิดตัวเซิร์ฟเวอร์ Helios และชิป Instinct MI400 ในงาน Advancing AI 2026 — [Blognone](https://www.blognone.com/node/151219)

ในงาน AMD Advancing AI 2026 บริษัทเปิดตัวชิปกราฟิกศูนย์ข้อมูลตระกูล Instinct MI400 สองรุ่นแรก ได้แก่ MI455X สำหรับโรงงานผลิตโทเค็น AI และ MI430X สำหรับสภาพแวดล้อมควบคุม โดย MI455X ใช้เทคโนโลยี 2nm พร้อมหน่วยความจำ HBM4 สูงสุด 432GB ต่อชิป แบนด์วิดท์ 23.3TB/s รองรับ MXFP8 ที่ 20.13 เพตาฟลอปและ MXFP4 ที่ 40.26 เพตาฟลอป พร้อมกันนี้ AMD ยังเปิดตัวเซิร์ฟเวอร์ Helios ชุดแร็ค 72 ชิปต่อตู้ ที่บริษัทระบุว่าให้ประสิทธิภาพต่อราคาดีกว่า Nvidia Vera Rubin NVL72 ถึง 30% ([Blognone](https://www.blognone.com/node/151221))

จุดที่น่าสนใจกว่าตัวเลขสเปกคือ AMD ไม่ได้แข่งแค่ระดับชิป แต่แข่งทั้งแร็ค เครือข่าย และซอฟต์แวร์พร้อมกัน — "ประสิทธิภาพต่อโทเค็น" กำลังกลายเป็นหน่วยวัดมาตรฐานใหม่แทน FLOPS ดิบ เพราะสะท้อนต้นทุนรันโมเดลจริงมากกว่า และสิ่งที่ยืนยันว่านี่ไม่ใช่แค่ demo เปรียบเทียบคือรายชื่อผู้ใช้ Helios ตั้งแต่วันแรก ทั้ง Microsoft, Meta, OpenAI, Oracle และ Anthropic ซึ่ง Tom Brown ผู้ร่วมก่อตั้ง Anthropic ยืนยันว่าทดสอบใช้งานจริงมาแล้วก่อนเปิดตัว สำหรับทีมวิศวกรรมที่พึ่ง CUDA เพียงอย่างเดียว นี่คือสัญญาณให้เริ่มทดสอบ workload บน ROCm stack คู่ขนาน เพราะการมี hyperscaler หลายเจ้าใช้ Helios จริงหมายความว่า capacity และราคาทางเลือกจะเข้าตลาดเร็วกว่าที่คาด

### 2. OpenAI นำ GPT-Live ควบคุมด้วยเสียงแบบ full-duplex เข้าสู่ Codex และ ChatGPT desktop — [VentureBeat](https://venturebeat.com/orchestration/agentic-coding-goes-hands-free-as-openai-brings-gpt-lives-full-duplex-voice-control-to-codex-and-chatgpt-on-the-desktop)

สองสัปดาห์หลังเปิดตัวโมเดลเสียง GPT-Live ที่ฟังและพูดพร้อมกันได้ (full-duplex) OpenAI นำความสามารถนี้เข้าสู่แอป ChatGPT desktop บน macOS และ Windows โดยเชื่อมตรงกับ Codex และ ChatGPT Work ให้วิศวกรซอฟต์แวร์สั่งงานหลายเธรดพร้อมกัน รีวิว pull request หรือ debug แอปพลิเคชันด้วยคำสั่งเสียงได้ ครอบคลุมผู้ใช้งานกว่า 10 ล้านคนต่อสัปดาห์ของ Codex และ ChatGPT Work

การแยก audio model (GPT-Live) ออกจาก reasoning model (GPT-5.5) แล้วให้ทำงานร่วมกันแบบ real-time ช่วยลด latency การสนทนาได้มากโดยไม่ต้องแลกกับความสามารถ reasoning และการเปลี่ยนจาก turn-based เป็น full-duplex ยังเปิดคำถามด้านการออกแบบ interaction ใหม่ทั้งหมด ไม่ใช่แค่ต่อยอดจาก text chat เดิม ในแง่ปฏิบัติ ฟีเจอร์นี้เปลี่ยน workflow การ pair-programming ได้จริง เพราะลดการสลับโฟกัสจากคีย์บอร์ดเมื่อทำงานหลายหน้าจอ แต่ทีมต้องวางแนวทาง code review ให้รัดกุมขึ้น เพราะคำสั่งเสียงอาจคลุมเครือกว่าการพิมพ์

### 3. Microsoft เปิดตัวโมเดล AI ของตัวเอง อ้างลดต้นทุนได้ถึง 89% เทียบกับ OpenAI — [VentureBeat](https://venturebeat.com/infrastructure/microsoft-launches-new-in-house-ai-models-it-says-cut-costs-up-to-89-versus-openai)

Microsoft AI เปิด public preview โมเดลใหม่ของตัวเอง 2 ตัว คือ MAI-Image-2.5-Pro โมเดลสร้างภาพความละเอียดสูงสุดของบริษัท และ MAI-Voice-2-Flash โมเดลเสียงสำหรับงาน enterprise ปริมาณมาก พร้อมเผยข้อมูลการทดสอบที่อ้างว่าต้นทุนต่ำกว่าโมเดลเทียบเท่าของ OpenAI ถึง 89%

### 4. DeepSeek เปิดตัว DeepSeek-V4 จุดชนวนสงครามราคาโมเดล AI จีน — [The Standard](https://thestandard.co/deepseek-v4-ai-price-war-us-giants/)
