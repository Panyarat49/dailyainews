### 1. Reuters เผยกองทัพจีนใช้ AI สหรัฐฯ ผ่าน Model Distillation ยกระดับขีดความสามารถทางทหาร — [The Standard](https://thestandard.co/china-military-taps-us-ai/)
Reuters ตรวจสอบเอกสารทางวิชาการและสิทธิบัตรของจีนมากกว่า 80 ฉบับ พบว่านักวิจัยในสังกัดกองทัพจีนกำลังใช้เทคนิค "model distillation" ดึงผลลัพธ์และกระบวนการให้เหตุผล (reasoning) จากโมเดล AI ระดับแนวหน้าของสหรัฐฯ ทั้ง OpenAI และ Anthropic มาฝึกฝน AI ขนาดเล็กเฉพาะทางภายในประเทศ เพื่อใช้ในระบบสอดแนม สงครามไซเบอร์ และการตัดสินใจทางยุทธวิธี โดยไม่ต้องพึ่งพา compute มหาศาลเหมือนการพัฒนา frontier model จากศูนย์ — เป็น "ทางลัด" หลบเลี่ยงผลของมาตรการควบคุมการส่งออกชิปขั้นสูงจากสหรัฐฯ

เคสนี้ตอกย้ำข้อจำกัดของการควบคุม AI ด้วยการปิดกั้นชิปเพียงอย่างเดียว เพราะสิ่งที่ถูกดึงไปคือ output ผ่าน API ไม่ใช่ตัว weight หรือ hardware ต้นทาง ทำให้ export control ไม่สามารถปิดช่องทางนี้ได้ทั้งหมด นักวิจัยชี้ว่าสิ่งที่กองทัพจีนต้องการไม่ใช่แค่คำตอบที่ถูกต้อง แต่คือกระบวนการคิดวิเคราะห์ที่มีมูลค่าสูงเบื้องหลังคำตอบนั้น ซึ่งยากกว่าจะป้องกันด้วยวิธีทั่วไป ทีมที่ให้บริการ API สาธารณะจึงต้องกลับมาทบทวนเรื่อง rate-limit, การติดตาม usage ผิดปกติ และความเป็นไปได้ในการ watermark chain-of-thought อย่างจริงจัง

เหตุการณ์นี้เป็นบทเรียนสำคัญว่า "sandbox isolation" ไม่ใช่ข้อสมมติที่ปลอดภัยเสมอไป — ความผิดพลาดของมนุษย์ในการตั้งค่าโครงสร้างพื้นฐานคือช่องโหว่จริง ไม่ใช่ความสามารถ hacking ระดับสูงของตัวโมเดลเอง เพราะเทคนิคที่ใช้เป็นเรื่องพื้นฐานที่มนุษย์มองข้าม สำหรับทีมที่รัน AI agent แบบให้สิทธิ์เข้าถึงเครือข่ายจริง บทเรียนตรงคือต้อง verify การตัด egress/network isolation ด้วยการทดสอบอิสระ ไม่พึ่งพา prompt-level instruction ("ไม่มี internet access") เพียงอย่างเดียว
