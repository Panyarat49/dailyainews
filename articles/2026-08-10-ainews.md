### 1. Anthropic ตั้งแผนกออกแบบชิปคัสตอมสำหรับรัน Claude โดยเฉพาะ — [Blognone](https://www.blognone.com/node/151327)
Anthropic เปิดเผยว่าได้จัดตั้งทีมภายในเพื่อรับผิดชอบงานออกแบบชิปคัสตอมสำหรับใช้กับโมเดล Claude โดยเฉพาะ ตามที่หลายฝ่ายคาดการณ์ไว้ก่อนหน้านี้ พร้อมเปิดรับสมัครวิศวกรที่มีประสบการณ์ออกแบบชิปทั้งฝั่งฮาร์ดแวร์และซอฟต์แวร์ เป้าหมายคือให้การรัน Claude เร็วและมีประสิทธิภาพขึ้นรองรับดีมานด์ลูกค้าที่โตต่อเนื่อง โดยที่ผ่านมา Anthropic พึ่งพาฮาร์ดแวร์จาก Google, Amazon และ NVIDIA และเพิ่งมีข่าวหารือกับ Samsung เรื่องการผลิตชิปเมื่อเดือนก่อน

การที่ AI lab ระดับ frontier ลงมือออกแบบฮาร์ดแวร์เองสะท้อนบทเรียนสำคัญว่า system-software co-design กำลังกลายเป็นความได้เปรียบเชิงแข่งขันที่แยกจากขนาดโมเดลไม่ได้ นี่คือก้าวตามรอย Google TPU และ Amazon Trainium — Anthropic กำลังกระจายความเสี่ยงด้าน supply และแย่งชิง cost-per-token ให้ต่ำลงผ่านชิปที่ optimize เฉพาะสถาปัตยกรรม Claude ในระยะสั้นยังไม่กระทบ API ที่ใช้อยู่ แต่ทีมที่ build บน Claude ควรจับตาว่าชิปคัสตอมนี้จะมาในรูป latency ที่ต่ำลงหรือ pricing tier ใหม่เมื่อไร เพราะมักเป็นสัญญาณล่วงหน้าของการเปลี่ยนโครงสร้างต้นทุนที่ pass ต่อมาถึงนักพัฒนา

### 2. Situational Awareness ทุ่ม $400M ลงทุนในสตาร์ทอัพชิป Source Foundry — [TechCrunch](https://techcrunch.com/2026/08/09/embattled-hedge-fund-situational-awareness-invests-400m-in-chip-startup-source-foundry/)
กองทุน Situational Awareness ของ Leopold Aschenbrenner อดีตนักวิจัย OpenAI ลงทุนเพิ่มอีก 400 ล้านดอลลาร์ใน Source Foundry สตาร์ทอัพผลิตชิปที่ก่อตั้งโดยนักวิจัย Stanford ทำให้ยอดลงทุนสะสมในบริษัทนี้แตะ 500 ล้านดอลลาร์ ทั้งที่กองทุนเพิ่งขายพอร์ตสาธารณะส่วนใหญ่ให้ Citadel เมื่อปลายเดือนกรกฎาคม หลังสินทรัพย์ภายใต้การจัดการร่วงจาก 2 หมื่นล้านเหลือ 1 หมื่นล้านดอลลาร์ ท่ามกลางหุ้นกลุ่ม AI infrastructure ที่ปรับตัวลง แต่กองทุนยังคงถือหุ้น Anthropic ไว้

กรณีนี้เป็นตัวอย่างเชิงบทเรียนเรื่อง concentration risk ในวงการลงทุน AI — กองทุนที่เพิ่งเจ็บตัวหนักยังเลือกเพิ่ม exposure ในสตาร์ทอัพชิปเดี่ยว สะท้อนความเชื่อว่า capacity การผลิตชิปคือคอขวดที่แท้จริงของอุตสาหกรรม มากกว่าการแข่งขันที่ตัวโมเดล Source Foundry เจาะปัญหาที่จับต้องได้จริงคือการผลิตชิปให้เร็วและถูกลง ซึ่งถ้าสำเร็จจะกระทบทั้งอุตสาหกรรม ยังเป็นข่าวระดับการเงินที่ไม่กระทบ tooling ทันที แต่ถ้าลดต้นทุนการผลิตชิปได้จริง ในระยะ 1-2 ปีอาจเห็นราคา compute สำหรับ inference ถูกลง ซึ่งทีม infra ควรใส่ไว้ในสมการวางแผนต้นทุนระยะยาว

### 3. Anthropic เปิด auto mode เป็นค่าเริ่มต้นให้ Claude Code — [TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/)
Anthropic ประกาศจะเปิด auto mode เป็นค่าเริ่มต้นสำหรับบัญชี Pro, Max และ Team ของ Claude Code ตั้งแต่วันที่ 14 สิงหาคมเป็นต้นไป โดยแทนที่จะขอ approval จากมนุษย์ทุกขั้นตอน ระบบจะดำเนินการต่อเนื่องเว้นแต่การกระทำนั้นถูกประเมินว่า "ย้อนกลับไม่ได้ ทำลายล้าง หรือมุ่งออกนอกสภาพแวดล้อม" บริษัทอ้างผลทดสอบกับผู้ใช้ paid 1,053 คนพบว่า auto mode ดักจับการกระทำอันตรายได้ถึง 89% เทียบกับ manual review ที่ทำได้เพียง 13.6% พร้อมเสริมมาตรการ prompt injection screening และ hard deny rules ที่ปรับแต่งได้เพื่อป้องกัน data exfiltration

ตัวเลข 89% เทียบ 13.6% เป็นกรณีศึกษาเรื่อง automation bias ที่ดี — เมื่อมนุษย์ approve prompt ซ้ำจนกลายเป็นนิสัย (สูงถึง 97% ของครั้ง) การตรวจสอบโดยมนุษย์อาจไม่ปลอดภัยไปกว่าระบบอัตโนมัติที่ออกแบบมาดี การเปิด auto mode เป็นค่าเริ่มต้นคือก้าวสำคัญสู่ agentic coding แบบเต็มรูปแบบ แต่ก็เพิ่มพื้นที่เสี่ยงที่ต้องติดตามว่ามาตรการป้องกันเพียงพอในสภาพแวดล้อม production จริงหรือไม่ ทีมที่ใช้ Claude Code ควรตรวจสอบ permission settings ก่อนวันที่ 14 ส.ค. โดยเฉพาะ repo ที่มี credentials หรือ production access ควร set custom hard deny rules ไว้ล่วงหน้าแทนที่จะพึ่ง default
