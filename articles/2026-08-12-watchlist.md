Sundar Pichai โพสต์บน X ว่าแอป Gemini มีผู้ใช้เกิน 1 พันล้านคนต่อเดือนแล้ว เป็นผลิตภัณฑ์ Google ตัวที่ 14 ที่ทำได้ และเป็นตัวที่โตเร็วที่สุดเท่าที่เคยมีมา โดย 63% ของผู้ใช้คุยกับ Gemini ผ่านเสียงโดยตรง สร้างภาพมากกว่า 150 ล้านภาพต่อวัน และมีผู้ใช้บน iOS เกิน 100 ล้านคน ตัวเลขนี้มาไล่หลัง ChatGPT ที่แตะพันล้านผู้ใช้เมื่อเดือนมิถุนายน

ตัวเลขนี้เป็นกรณีศึกษาความเร็วของการแพร่กระจายเทคโนโลยีชั้นดี แต่คำถามที่น่าสนใจกว่าคือ "พันล้านผู้ใช้" วัดจากอะไร เพราะ Google แยกตัวเลข AI Mode ใน Search ออกต่างหากจากแอป Gemini เอง — และสัดส่วนผู้ใช้ที่คุยด้วยเสียงถึง 63% สะท้อนว่า voice-first กำลังกลายเป็นทางหลักจากการฝัง Gemini เข้าไปทั่ว Android/Search/Workspace ทีมที่ integrate ผ่าน Gemini API ควรจับตาว่าปริมาณ inference ระดับนี้จะกระทบ rate limit หรือราคาต่อ token ของ API สาธารณะหรือไม่

### 2. Nvidia (NVDA US · Tier 1) — Nvidia unveils first open-source AI model since CEO Jensen Huang entered the chat — [CNBC](https://www.cnbc.com/2026/08/11/nvidia-releases-nemotron-3point5-lightning-open-source-ai-model-.html)

ดีลนี้สะท้อนความขัดแย้งเชิงกลยุทธ์ที่มีเหตุผลธุรกิจแฝงอยู่ — Nvidia ไม่ได้แข่งขายโมเดล แต่ยิ่งมีโมเดลเปิดมากยิ่งกระตุ้นดีมานด์ชิปของตัวเอง จุดเด่นของ Nemotron 3.5 Lightning คือ latency ต่ำระดับ edge ที่โมเดลเปิดขนาดใหญ่ทำได้ไม่ดีเท่า สำหรับนักพัฒนาที่มองหาโมเดลรันบนเครื่อง local สำหรับงาน agent เฉพาะทางโดยไม่ต้องพึ่ง cloud API ตลอดเวลา นี่คือตัวเลือกที่ควรลองเทียบต้นทุนกับการเรียก API ภายนอก

**3.1 AI startup Manus to resume independent operations as deal with Meta unwinds — [CNBC](https://www.cnbc.com/2026/08/11/manus-china-meta-acquisition.html)**

**3.2 Meta เปิดตัว Muse Glimmer AI ขนาด 30 พันล้านพารามิเตอร์ พร้อมเปิดค่าน้ำหนัก Muse Spark 1.2 — [Techsauce](https://techsauce.co/ai/meta-muse-glimmer-open-weight-muse-spark-1-2)**

การปล่อยโมเดลขนาดที่รันบนโน้ตบุ๊กได้เป็นทิศทางที่ดีสำหรับการทดลองสร้างแอป AI แบบ on-device โดยไม่ต้องเสียค่า API ต่อเนื่อง ควรตามดูว่า benchmark เทียบกับ Nemotron 3.5 Lightning ของ Nvidia ที่ออกในสัปดาห์เดียวกันแล้วใครแรงกว่าในงาน agentic โมเดลขนาด 30B ที่โอเพนซอร์สนี้เหมาะกับทีมพัฒนาไทยที่อยากทำ prototype หรือ product ที่ต้องการความเป็นส่วนตัวสูง
