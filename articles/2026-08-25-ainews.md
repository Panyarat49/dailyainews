Artificial Analysis เผยเบนช์มาร์กอิสระชุดแรกของ Nvidia LPX rack ที่ใช้ชิป Groq 3 LPU ทำความเร็วได้ 3,400 token ต่อวินาทีบนโมเดล Gemma 4 31B ด้วย input ยาวถึง 100,000 token เร็วกว่าคู่แข่งใกล้เคียงที่สุดอย่าง Cerebras (882 tok/s) ถึง 4 เท่า Groq ใช้สถาปัตยกรรม SRAM-heavy dataflow ที่ต่างจาก GPU ทั่วไปที่พึ่ง HBM โดยสิ้นเชิง ซึ่ง Nvidia ซื้อกิจการ Groq ไปเมื่อปลายเดือนธันวาคมด้วยมูลค่าราว 2 หมื่นล้านดอลลาร์

ตัวเลขนี้เป็นหลักฐานเชิงประจักษ์ชิ้นแรกที่ยืนยันว่าดีลซื้อกิจการ Groq ไม่ได้เป็นแค่การป้องกันคู่แข่งไม่ให้เติบโต แต่ Nvidia ได้เทคโนโลยีที่ใช้งานได้จริงในสเกลใหญ่ และตอกย้ำบทเรียนสำคัญว่า memory bandwidth ไม่ใช่ raw compute คือคอขวดหลักของงาน inference ที่ context ยาวขึ้นเรื่อยๆ ทีมที่รันงาน long-context inference หรือ RAG ควรจับตาว่า LPX rack จะเปิดให้ใช้งานทั่วไปเมื่อไรและราคาเท่าไร เพราะ throughput ระดับนี้อาจเปลี่ยนสมการต้นทุนของงานที่ต้องประมวลผล context ยาวอย่างมีนัยสำคัญ

The Information รายงานว่า Nvidia กำลังเจรจาเพื่อร่วมลงทุนในรอบระดมทุนใหม่ของ Perplexity ที่คาดว่ามูลค่ากิจการจะอยู่ที่ 3 หมื่นล้านดอลลาร์หรือมากกว่า รายได้ต่อเนื่อง 12 เดือนของ Perplexity เพิ่มขึ้นเป็นกว่า 750 ล้านดอลลาร์ จากราว 250 ล้านดอลลาร์เมื่อต้นปี โดยมีปัจจัยหนุนจากบริการ Perplexity Computer ที่ให้ AI agent ทำงานแทนผู้ใช้บนคอมพิวเตอร์
