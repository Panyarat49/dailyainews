### 1. OpenAI โชว์ชิป inference คัสตอม Jalapeño ที่ Hot Chips 2026 อ้างแรงกว่า Nvidia GB300 — [The Register](https://www.theregister.com/systems/2026/08/25/openais-upcoming-jalapeno-chip-looks-like-itll-be-an-inference-beast/5292052)

OpenAI เปิดรายละเอียดชิป AI accelerator คัสตอม "Jalapeño" ที่พัฒนาร่วมกับ Broadcom ในงาน Hot Chips ที่ Stanford — แร็ครวม 128 ชิป ให้กำลังประมวลผล 1.7 exaFLOPS และหน่วยความจำ HBM 27TB ตามรายงานของ Tom's Hardware ชิป ASIC ขนาด 700W ตัวนี้อ้างว่าให้ throughput ต่อกิโลวัตต์สูงกว่า Nvidia GPU เรือธง 1,400W ถึง 1.9 เท่า และ latency ต่ำกว่า 3.6 เท่า บนเบนช์มาร์ก InferenceX ของ SemiAnalysis (ยืนยันซ้ำโดย TechCrunch) โดยจะเริ่มทยอยใช้งานปลายปีนี้และเข้าสู่การผลิตจริงในปี 2027 ทั้งนี้ OpenAI ยังไม่ตัดขาดพาร์ทเนอร์ฮาร์ดแวร์เดิมอย่าง Nvidia และ AMD ที่ยังต้องใช้สำหรับงาน training

การที่ OpenAI ก้าวเข้าสู่การออกแบบชิปของตัวเองตอกย้ำว่า vertical integration ด้านฮาร์ดแวร์กำลังกลายเป็นความจำเป็นเชิงแข่งขันสำหรับ AI lab ระดับ frontier ไม่ต่างจากที่ Google ทำกับ TPU มาก่อน ตัวเลข 1.9 เท่าที่อ้างมาจากฝั่ง OpenAI เอง ยังต้องรอการพิสูจน์อิสระเมื่อเข้าสู่ volume production จริงในปี 2027 ระยะสั้นนี้ยังไม่กระทบ API ที่นักพัฒนาใช้อยู่ เพราะ OpenAI ยังพึ่งพา Nvidia/AMD ในการ deploy ช่วงแรก แต่ชิปเฉพาะทางลักษณะนี้มักตามมาด้วยโครงสร้างราคาต่อ token ที่เปลี่ยนไปในระยะ 1-2 ปีข้างหน้า ทีมที่วางแผนงบประมาณ inference ระยะยาวควรติดตามความคืบหน้าของ Jalapeño ไว้เป็นปัจจัยหนึ่ง

### 2. Perplexity จับมือ Nvidia เปิดตัว Portable Computer เอเจนต์ AI ที่รันบนเครื่องผู้ใช้เอง — [VentureBeat](https://venturebeat.com/infrastructure/perplexity-partners-with-nvidia-to-launch-portable-computer-a-fully-local-ai-agent-with-zero-token-costs)

Perplexity เปิดตัว Portable Computer เวอร์ชันหนึ่งของแพลตฟอร์มเอเจนต์ "Computer" ที่รันได้ทั้งหมดบนฮาร์ดแวร์ที่ผู้ใช้มีอยู่แล้ว เริ่มจาก Nvidia DGX Spark และเครื่อง Linux ที่มี Nvidia RTX GPU พัฒนาร่วมกับ Nvidia อย่างใกล้ชิด โมเดล ไฟล์ผู้ใช้ และงานทั้งหมดอยู่บนเครื่องเอง ทำงานโดยไม่เสีย billing credit ใดๆ ถือเป็นความพยายามที่จริงจังที่สุดครั้งหนึ่งในการย้าย workload AI agent ออกจาก cloud มาสู่อุปกรณ์ท้องถิ่น

กรณีนี้เป็นตัวอย่างชัดเจนของการเปลี่ยนสมการระหว่าง edge computing กับ cloud computing ในบริบท AI agent — การย้ายงานมาที่เครื่องผู้ใช้โดยตรงเปลี่ยนทั้งเรื่องความเป็นส่วนตัวของข้อมูลและโครงสร้างต้นทุน จุดขายหลักคือ "zero token cost" เพราะรันบนฮาร์ดแวร์ของผู้ใช้เอง แต่ต้องแลกกับพลัง compute ที่จำกัดกว่าโมเดลบน cloud จึงต้องดูว่า Perplexity เลือกใช้โมเดลขนาดที่พอเหมาะกับฮาร์ดแวร์ผู้บริโภคอย่างไร สำหรับทีมที่กังวลเรื่อง data residency หรือต้นทุน API ต่อเนื่อง นี่คือทางเลือกที่น่าจับตาสำหรับงาน agentic ที่ไม่ต้องการ context ขนาดใหญ่มาก โดยเฉพาะงานที่มีข้อมูลอ่อนไหวที่ไม่อยากส่งขึ้น cloud

### 3. Anthropic รวมระบบความจำ Claude chat กับ Claude Cowork เข้าด้วยกัน — [TechCrunch](https://techcrunch.com/2026/08/25/claude-cowork-finally-remembers-what-you-told-the-app-in-chat/)

Anthropic ประกาศรวมระบบความจำของ Claude chat และ Claude Cowork เข้าด้วยกัน ทำให้ Claude จดจำสิ่งที่เรียนรู้จากพื้นที่หนึ่งได้แม้กำลังใช้งานอีกพื้นที่หนึ่ง แก้ปัญหาความรำคาญคลาสสิกของการต้อง rebrief AI ซ้ำทุกครั้ง ตามรายงานของ ZDNet มีตัวเลือก opt-out ให้ผู้ใช้ที่ไม่ต้องการแชร์ความจำข้ามระบบ พร้อมตั้งคำถามเรื่องความเป็นส่วนตัวว่าข้อมูลที่ AI "จำ" ไว้คุ้มค่ากับความสะดวกที่ได้แลกมาหรือไม่

การรวมระบบความจำข้ามแพลตฟอร์มเป็นกรณีศึกษาที่ดีเรื่อง context continuity ใน AI assistant — ปัญหาที่ผู้ใช้ต้องบอกซ้ำทุกครั้งเป็นข้อจำกัดคลาสสิกของ AI แบบ stateless และโจทย์ทางเทคนิคที่ต้องแก้คือการ merge memory store ให้เข้ากับบริบทที่ต่างกัน (แชทแบบสนทนา vs Cowork แบบทำงาน agentic) โดยไม่ทำให้ข้อมูลปนกันจนกลายเป็น noise ทีมที่ใช้ Claude กับงานที่มีข้อมูลลูกค้าหรือความลับทางธุรกิจควรตรวจสอบ memory settings และนโยบายการแชร์ข้อมูลข้าม session ก่อนเปิดใช้ฟีเจอร์นี้เต็มรูปแบบ

### 4. Apple เปิดตัวชิป M6 และ M5 Ultra รองรับการประมวลผล AI ที่มากขึ้น — [Blognone](https://www.blognone.com/node/151459)

Apple เปิดตัวชิป Apple Silicon สองรุ่นใหม่พร้อมอัปเดต Mac mini และ Mac Studio ได้แก่ M6 ชิปที่ผลิตด้วยเทคโนโลยี 2 นาโนเมตรตัวแรกของบริษัท มี Neural Engine แบบ 16 คอร์คู่ ซีพียู 12 คอร์ และจีพียู 12 คอร์ รองรับหน่วยความจำสูงสุด 32GB และ M5 Ultra ที่ใช้เทคโนโลยี UltraFusion เชื่อมชิป M5 Max สองตัวเข้าด้วยกัน ให้ซีพียูสูงสุด 36 คอร์ จีพียูสูงสุด 80 คอร์ และ Neural Engine 32 คอร์ ทั้งสองรุ่นเน้นการประมวลผล AI บนเครื่องที่เร็วขึ้นชัดเจน

M6 เป็นชิป 2 นาโนเมตรตัวแรกของ Apple เป็นตัวอย่างสอนเรื่อง process node scaling และผลต่อประสิทธิภาพ Neural Engine ที่เพิ่มขึ้นแบบก้าวกระโดด Neural Engine 16 คอร์คู่บน M6 และสถาปัตยกรรม UltraFusion ของ M5 Ultra ทำให้การรันโมเดล on-device ขนาดใหญ่ขึ้นเป็นไปได้จริงมากขึ้นโดยไม่ต้องพึ่ง cloud inference ตลอดเวลา นักพัฒนาที่ทำแอป on-device AI บน macOS ควรทดสอบว่าโมเดลที่เคยรันบน M3/M4 ได้ประโยชน์จากแบนด์วิธหน่วยความจำและ Neural Engine ใหม่แค่ไหน ก่อนวางแผนอัปเกรดฮาร์ดแวร์สำหรับงาน dev หรือ production
