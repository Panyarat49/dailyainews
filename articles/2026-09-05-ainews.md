### 1. OpenAI เปิดตัว GPT-6 Astra ประกาศ "ยุค AGI" — [Blognone](https://www.blognone.com/node/151533)

OpenAI เปิดตัว GPT-6 Astra โดยชูจุดเด่นเรื่องความสามารถใช้งานคอมพิวเตอร์แทนมนุษย์ (computer use) — ท่องเว็บ กรอกสเปรดชีต ทำงานหลายขั้นตอนข้ามแอปพลิเคชันได้เอง — พร้อมทำคะแนนอิ่มตัวใน FrontierMath Tier 4 (98%), ARC-AGI-3 (99.9%) และ ExploitBench (100%) ในงานแถลงข่าวแบบปิด ประธาน Greg Brockman ทิ้งท้ายว่า "welcome to the AGI era" โดยระบุว่าตัวเขาเองเชื่อว่า OpenAI มาถึงจุด AGI แล้ว แต่เปิดให้ผู้ใช้ตัดสินเอง โมเดลจะเปิดให้กลุ่มจำกัดผ่านโครงการ Daybreak Access ก่อน แล้วค่อยขยายสู่ ChatGPT และ API ทั่วไป "ในไม่กี่วันข้างหน้า" (ยืนยันซ้ำโดย VentureBeat, 9to5Mac, Axios)

การใช้คำว่า "ยุค AGI" ในที่นี้เป็นตัวอย่างสอนที่ดีว่าคำดังกล่าวยังไม่มีนิยามทางวิชาการที่เป็นฉันทามติ ต่างจากตัวเลขเบนช์มาร์กที่วัดผลได้ชัดเจน — การอิ่มตัวพร้อมกันของ FrontierMath และ ARC-AGI-3 บ่งชี้ว่าชุดเบนช์มาร์กนี้เริ่มหมดประโยชน์ในการวัดความก้าวหน้าต่อไป จุดที่ต้องพิสูจน์จริงคือความสามารถ computer-use ในงานที่ซับซ้อนนอกห้องทดลอง ทีมพัฒนาที่วางแผนสร้าง workflow อัตโนมัติควรรอทดสอบ capability จริงเมื่อเข้าถึง API ได้ก่อน แทนที่จะวางแผนตามคำประกาศของผู้บริหารอย่างเดียว

### 2. สหรัฐฯ เปิดสอบสวน Tesla Cybercab หนึ่งวันหลังเปิดให้บริการจริงที่ออสติน — [CNBC](https://www.cnbc.com/2026/09/04/us-auto-safety-regulator-opens-probe-into-nearly-1000-tesla-cybercabs.html)

หน่วยงานความปลอดภัยทางถนนของสหรัฐฯ (NHTSA) เปิดการตรวจสอบ Tesla Cybercab เกือบ 1,000 คัน หนึ่งวันหลัง Tesla เริ่มให้บริการรถไร้คนขับเชิงพาณิชย์จริงที่ออสติน เท็กซัส โดยตั้งคำถามว่า Tesla รับรองมาตรฐานความปลอดภัยของรถที่ไม่มีพวงมาลัย เบรก คันเร่ง หรือกระจกมองหลัง ได้อย่างไร NHTSA จะตรวจสอบกระบวนการและข้อมูลทางเทคนิคที่ Tesla ใช้ตัดสินเองว่ามาตรฐานความปลอดภัยยานยนต์ของรัฐบาลกลางบางข้อไม่บังคับใช้กับรถรุ่นนี้ (ยืนยันซ้ำโดย TechCrunch, Reuters)

กรณีนี้เป็นตัวอย่างชัดเจนของช่องว่างระหว่างนวัตกรรมกับกรอบกฎหมายที่ร่างไว้สำหรับรถที่มีคนขับ ประเด็นสำคัญไม่ใช่ตัวซอฟต์แวร์ขับขี่อัตโนมัติเอง แต่คือกระบวนการ self-certification ที่ Tesla ใช้ตัดสินใจฝ่ายเดียวว่ามาตรฐานใดบังคับใช้กับตน ซึ่งเป็นความเสี่ยงเชิงกระบวนการมากกว่าความเสี่ยงทางเทคนิคของโมเดล ทีมที่ทำงานกับระบบ autonomous หรือ robotics ควรทบทวนเอกสาร compliance ของตัวเองล่วงหน้า เพราะหน่วยงานกำกับดูแลเริ่มตรวจสอบเร็วขึ้นทันทีหลังการเปิดตัวผลิตภัณฑ์ใหม่

### 3. Microsoft เปิดตัว MAI-Transcribe-2 โมเดลถอดเสียงเร็วและถูกที่สุดในตลาด — [VentureBeat](https://venturebeat.com/infrastructure/microsoft-ais-mai-transcribe-2-undercuts-openai-google-and-elevenlabs-on-price-and-speed)

Microsoft AI เปิดตัว MAI-Transcribe-2 โมเดลถอดเสียงเป็นข้อความที่รองรับ 60 ภาษา แยกผู้พูดได้ ใส่ timestamp ระดับคำ และทำงานได้ดีในสภาพแวดล้อมเสียงรบกวน โมเดลนี้ขึ้นอันดับหนึ่งในเบนช์มาร์ก FLEURS ด้วยอัตราความผิดพลาดเฉลี่ย 5.2% และประมวลผลไฟล์เสียงยาวได้เร็วกว่า GPT-Transcribe ของ OpenAI ถึง 10 เท่า เร็วกว่า Scribe v2 ของ ElevenLabs 7 เท่า และเร็วกว่า Gemini 3.5 Transcribe ของ Google 5 เท่า พร้อมราคาเปิดตัว $0.10 ต่อชั่วโมงเสียงถึงสิ้นปี 2026 (ยืนยันซ้ำโดย Microsoft AI, Unite.AI)

การที่ Microsoft สร้างโมเดลถอดเสียงเองแทนที่จะพึ่ง OpenAI ทั้งหมด สะท้อนกลยุทธ์กระจายความเสี่ยงด้าน AI infrastructure ของ Big Tech ที่ไม่อยากผูกติดกับผู้ให้บริการรายเดียวแม้จะเป็นพันธมิตรกันอยู่ ตัวเลขเบนช์มาร์กสาธารณะอย่าง FLEURS ทำให้เทียบประสิทธิภาพข้ามผู้ให้บริการได้เป็นระบบ แต่ราคา $0.10/ชั่วโมงเป็นราคาโปรโมชันชั่วคราวเท่านั้น ทีมที่ใช้ transcription ในงาน production ควรทดสอบคุณภาพกับ audio จริงของตัวเองก่อนย้ายระบบ และเตรียมงบประมาณรองรับราคาที่อาจปรับขึ้นหลังสิ้นปีนี้

### 4. Anthropic เปิดตัว Claude Fable 5.1 และ Claude Mythos 5.1 — [Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-1)

การคงราคาเดิมแต่ปรับปรุงประสิทธิภาพที่ effort ระดับสูงเป็นตัวอย่างสอนเรื่อง test-time compute — การให้โมเดล "คิดนานขึ้น" เพื่อผลลัพธ์ที่ดีขึ้น แทนที่จะแข่งขันกันที่ขนาดพารามิเตอร์อย่างเดียว ส่วนการแยก Mythos 5.1 ให้เข้าถึงได้เฉพาะกลุ่มที่ผ่านโครงการ trusted access สะท้อนแนวทาง tiered release ที่อุตสาหกรรมเริ่มใช้มากขึ้นกับโมเดลที่มีความเสี่ยงสูงกว่า cache read ที่ถูกลง 75% และ context window 1M token มีผลตรงต่อต้นทุนงาน agentic/coding ที่รันยาวต่อเนื่อง ทีมที่ใช้ Claude อยู่แล้วควรทดสอบ Fable 5.1 ที่ effort สูงกับงานที่เคยมีปัญหาความแม่นยำ
