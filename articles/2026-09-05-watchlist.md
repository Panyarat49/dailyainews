### 1. Nvidia (NVDA US · Tier 1) — ยืนยันดีลซื้อ Hugging Face มูลค่า 1.29 หมื่นล้านดอลลาร์ — [TechCrunch](https://techcrunch.com/2026/09/03/nvidia-confirms-it-will-buy-hugging-face-for-12-9-billion/)

Nvidia ยืนยันอย่างเป็นทางการว่าจะเข้าซื้อ Hugging Face แพลตฟอร์มแจกจ่ายโมเดล AI โอเพนซอร์สที่ใหญ่ที่สุด (ผู้ใช้กว่า 18 ล้านคน แชร์โมเดลกว่า 3 ล้านตัว) ด้วยมูลค่า 1.293 หมื่นล้านดอลลาร์ แบ่งเป็นเงินให้นักลงทุนราว 1.19 หมื่นล้านดอลลาร์ และเงินรักษาพนักงานอีกไม่เกิน 1 พันล้านดอลลาร์ Jensen Huang ซีอีโอ Nvidia ให้คำมั่นว่า Hugging Face จะยังเปิดเป็นแพลตฟอร์มกลางให้ทั้งอุตสาหกรรม ผู้ใช้ไม่จำเป็นต้องใช้ผลิตภัณฑ์ Nvidia และฮาร์ดแวร์จาก AMD, Intel จะยังใช้งานได้ต่อ ดีลนี้ต้องผ่านการอนุมัติจากหน่วยงานกำกับดูแลก่อน (ยืนยันซ้ำโดย Engadget, NBC News, Tom's Hardware, The Information)

### 2. Tesla (TSLA US · Tier 1) — สหรัฐฯ เปิดสอบสวน Cybercab หนึ่งวันหลังเปิดให้บริการจริงที่ออสติน — [CNBC](https://www.cnbc.com/2026/09/04/us-auto-safety-regulator-opens-probe-into-nearly-1000-tesla-cybercabs.html)

หน่วยงานความปลอดภัยทางถนนของสหรัฐฯ (NHTSA) เปิดการตรวจสอบ Tesla Cybercab เกือบ 1,000 คัน หนึ่งวันหลัง Tesla เริ่มให้บริการรถไร้คนขับเชิงพาณิชย์จริงที่ออสติน เท็กซัส โดยตั้งคำถามว่า Tesla รับรองมาตรฐานความปลอดภัยของรถที่ไม่มีพวงมาลัย เบรก คันเร่ง หรือกระจกมองหลัง ได้อย่างไร NHTSA จะตรวจสอบกระบวนการและข้อมูลทางเทคนิคที่ Tesla ใช้ตัดสินเองว่ามาตรฐานความปลอดภัยยานยนต์ของรัฐบาลกลางบางข้อไม่บังคับใช้กับรถรุ่นนี้ (ยืนยันซ้ำโดย TechCrunch, Reuters)

กรณีนี้เป็นตัวอย่างชัดเจนของช่องว่างระหว่างนวัตกรรมกับกรอบกฎหมายที่ร่างไว้สำหรับรถที่มีคนขับ ประเด็นสำคัญไม่ใช่ตัวซอฟต์แวร์ขับขี่อัตโนมัติเอง แต่คือกระบวนการ self-certification ที่ Tesla ใช้ตัดสินใจฝ่ายเดียวว่ามาตรฐานใดบังคับใช้กับตน ซึ่งเป็นความเสี่ยงเชิงกระบวนการมากกว่าความเสี่ยงทางเทคนิคของระบบ ทีมที่ทำงานกับระบบ autonomous หรือ robotics ควรทบทวนเอกสาร compliance ของตัวเองล่วงหน้า เพราะหน่วยงานกำกับดูแลเริ่มตรวจสอบเร็วขึ้นทันทีหลังเปิดตัวผลิตภัณฑ์ใหม่

### 3. Microsoft (MSFT US · Tier 1) — เปิดตัว MAI-Transcribe-2 โมเดลถอดเสียงเร็วและถูกที่สุดในตลาด — [VentureBeat](https://venturebeat.com/infrastructure/microsoft-ais-mai-transcribe-2-undercuts-openai-google-and-elevenlabs-on-price-and-speed)

การที่ Microsoft สร้างโมเดลถอดเสียงเองแทนที่จะพึ่ง OpenAI ทั้งหมด สะท้อนกลยุทธ์กระจายความเสี่ยงด้าน AI stack ของ Microsoft ที่ไม่อยากผูกติดกับพันธมิตรรายเดียวแม้จะลงทุนกับ OpenAI มหาศาล ตัวเลขเบนช์มาร์กสาธารณะอย่าง FLEURS ทำให้เทียบประสิทธิภาพข้ามผู้ให้บริการได้เป็นระบบ แต่ราคา $0.10/ชั่วโมงเป็นราคาโปรโมชันชั่วคราวเท่านั้น ทีมที่ใช้ transcription ใน production ควรทดสอบคุณภาพกับ audio จริงก่อนย้ายระบบ และเตรียมงบประมาณรองรับราคาที่อาจปรับขึ้นหลังสิ้นปี

### 4. Meta Platforms (META US · Tier 1) — เปิดตัว Muse Spark 1.3 โมเดลเรือธงใหม่ ไล่ตาม OpenAI/Anthropic — [VentureBeat](https://venturebeat.com/technology/meta-says-muse-spark-1-3-has-frontier-performance-but-its-best-results-come-from-a-model-developers-cant-broadly-use-yet)

Meta เปิดตัว Muse Spark 1.3 โมเดล multimodal ที่เน้นงาน agentic, multi-agent และ coding ที่ต้องรันต่อเนื่องยาวนาน ใช้ tool call น้อยลง 20% และโทเคนน้อยลง 25% เทียบกับ Muse Spark 1.2 ในการทดสอบภายในของ Meta Alexandr Wang ประธานเจ้าหน้าที่ AI ของ Meta ระบุว่าเป็นการก้าวกระโดดครั้งใหญ่ที่สุดของบริษัท ทำให้ Meta อยู่ในระดับเดียวกับโมเดลล่าสุดของ OpenAI และ Anthropic แล้ว แม้ว่าผลเบนช์มาร์กที่ดีที่สุดจะมาจาก configuration แบบ max reasoning ที่ยังอยู่ระหว่างทดสอบความปลอดภัยเพิ่มเติมและจะตามมา "ในไม่ช้า" (ยืนยันซ้ำโดย SiliconANGLE, MarkTechPost)

กรณีนี้เหมาะสอนเรื่อง benchmark gap ระหว่างโมเดลที่ปล่อยให้ใช้งานจริงกับ configuration สูงสุดที่ยังอยู่ระหว่างทดสอบความปลอดภัย ซึ่งเป็นรูปแบบที่พบบ่อยขึ้นในการเปิดตัวโมเดลเรือธง ตัวเลขลด tool call และ token สำคัญกว่าคำกล่าวอ้างเรื่อง "frontier performance" เพราะสะท้อนประสิทธิภาพเชิงต้นทุนของงาน agentic จริงมากกว่าคะแนนเบนช์มาร์กเดี่ยวๆ ทีมที่ใช้ Meta AI ในงาน coding/agentic ควรทดสอบ Muse Spark 1.3 กับ workload จริงที่รันยาวต่อเนื่อง และรอติดตาม max-reasoning configuration ที่ยังไม่เปิดให้ใช้งานกว้าง
