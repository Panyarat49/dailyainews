### 1. OpenAI เริ่มทยอยปล่อยโมเดล GPT-6 Astra พร้อมมาตรการความปลอดภัยไซเบอร์เพิ่มเติม — [CNBC](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html)

OpenAI ประกาศเมื่อวันพฤหัสบดีที่ 3 กันยายนว่าจะเริ่มทยอยปล่อยโมเดลใหม่ GPT-6 Astra ซึ่งบริษัทระบุว่าเป็นผลจาก "งานวิจัยและการเดิมพันครั้งใหญ่หลายปี" โดยบริษัทที่เข้าร่วมโปรแกรมความปลอดภัยไซเบอร์ Daybreak จะได้สิทธิ์เข้าถึงก่อน ตามด้วยผู้ใช้ ChatGPT Plus/Pro/Business/Enterprise และผ่าน API รวมถึง AWS บริษัทเพิ่มมาตรการป้องกันหลังเหตุการณ์ข้อมูลรั่วไหลของ Hugging Face และซีอีโอ Sam Altman ระบุว่าโมเดลนี้ผ่านกระบวนการรีวิวอย่างเป็นทางการร่วมกับรัฐบาลทรัมป์

การปล่อยโมเดลแบบเป็นเฟสพร้อมให้สิทธิ์กลุ่มความปลอดภัยไซเบอร์ก่อน สะท้อนแนวคิด responsible disclosure ที่ควรเป็นกรณีศึกษาด้าน AI governance ไม่ใช่แค่มุมการตลาด และการที่ต้องให้รัฐบาลสหรัฐฯ ร่วมรีวิวอย่างเป็นทางการบ่งชี้ว่าโมเดลระดับนี้เริ่มถูกมองเป็นความเสี่ยงระดับชาติมากกว่าผลิตภัณฑ์ทั่วไป ทีมที่ใช้ ChatGPT Enterprise หรือ API อยู่แล้วควรจับตาว่า Astra จะเปิดผ่าน AWS เมื่อไร และเตรียม guardrail ของตัวเองรองรับความสามารถ "ค้นหาช่องโหว่" ที่โมเดลระดับนี้มักมาพร้อมกัน

### 2. Anthropic เปิดตัว Claude Fable 5.1 และ Claude Mythos 5.1 ลดต้นทุนโค้ดดิ้งลงถึง 45% — [Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-1)

Anthropic เปิดตัว Claude Fable 5.1 (ให้ใช้งานทั่วไปแล้ว) และ Claude Mythos 5.1 (จำกัดเฉพาะโปรแกรม trusted-access) โดยระบุว่าเป็น "โมเดลเดียวกัน แต่มีระดับมาตรการป้องกันต่างกัน" Fable 5.1 มีต้นทุนถูกลงราว 25% สำหรับงานทั่วไป และลดลงถึง 45% สำหรับงาน agentic เข้มข้น จากการปรับราคา cache-read พร้อมลด false positive ด้านความปลอดภัยไซเบอร์ใน Claude Code ลงราว 60%

การแยกรุ่น Fable/Mythos ด้วยระดับ safeguard ต่างกันแต่เป็นโมเดลเดียวกันเป็นตัวอย่างที่ดีของนโยบาย tiered-access สำหรับงาน AI ที่มีความเสี่ยงสองด้าน และการลด false positive ด้านความปลอดภัยสะท้อนว่าจุดอ่อนหลักของโมเดล agentic รุ่นก่อนคือความแม่นยำในการตัดสินใจระหว่างทำงานยาว มากกว่าความสามารถพื้นฐาน ทีมที่ใช้ Fable 5 อยู่ควรทดสอบย้ายมาใช้รุ่นใหม่ทันทีเพื่อลดค่าใช้จ่าย โดยเฉพาะงานที่รันต่อเนื่องหลายชั่วโมง

### 3. Google เปิดตัว Gemini 3.8 Flash เทียบชั้น Opus 5 ด้านโค้ดดิ้ง — [Google DeepMind](https://deepmind.google/models/gemini/flash/)

Google ปล่อย Gemini 3.8 Flash เมื่อวันที่ 2 กันยายน โดยอ้างว่าเทียบเท่ากับ Opus 5 ของ Anthropic ในการทดสอบมาตรฐาน และในงานทดสอบภายในของ Google เอง วิศวกรที่เปรียบเทียบกับ Opus 5 ในงานโค้ดดิ้งซับซ้อนส่วนใหญ่เลือก Gemini 3.8 Flash เพราะ latency ต่ำกว่า ผลลัพธ์กระชับกว่า และมีอัตราการหลอน (hallucination) ต่ำกว่า ตัวโมเดลมีหน้าต่างบริบทถึง 1 ล้านโทเคน ราคาอยู่ที่ 0.75 ดอลลาร์ต่อล้านโทเคนอินพุต และ 3.75 ดอลลาร์ต่อล้านโทเคนเอาต์พุต

ควรอ่านตัวเลข benchmark เหล่านี้อย่างมีวิจารณญาณเพราะเป็นผลทดสอบภายในของ Google เอง แม้ตัวเลข latency ต่ำจะน่าเชื่อถือกว่าเรื่องคุณภาพโดยรวม แต่การที่ Flash-tier ไล่ทันรุ่น flagship ของคู่แข่งในงานจริงสะท้อนว่าความได้เปรียบของโมเดลราคาแพงเริ่มแคบลง ด้วยราคาที่ถูกกว่ารุ่น flagship มาก ทีมที่ทำ agentic coding ปริมาณสูงควรทดสอบใช้ Flash เป็นค่าเริ่มต้นแล้ว fallback ไปโมเดลใหญ่เฉพาะงานยาก
