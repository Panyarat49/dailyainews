### 3. Microsoft (MSFT · Tier 1) — Microsoft นำ GPT-6 Astra และ MAI-Transcribe-2 ขึ้น Azure AI Foundry — [Microsoft Azure Blog](https://azure.microsoft.com/en-us/blog/gpt-6-astra-frontier-intelligence-for-work-now-generally-available-in-microsoft-foundry/)

ในวันเดียวกับที่ OpenAI ปล่อย GPT-6 Astra (3 กันยายน) Microsoft ก็นำโมเดลนี้ขึ้น Microsoft Foundry ทันทีในราคา 10 ดอลลาร์ต่อล้านโทเคนอินพุตและ 50 ดอลลาร์ต่อล้านโทเคนเอาต์พุต พร้อมกันนั้นบริษัทยังเปิดตัวโมเดลเสียงของตัวเอง MAI-Transcribe-2 ที่เร็วกว่า GPT-Transcribe ถึง 10 เท่า และถูกกว่ารุ่นก่อนหน้าถึง 72% อยู่ที่ 0.10 ดอลลาร์ต่อชั่วโมง

### 4. Amazon (AMZN · Tier 1) — Anthropic พันธมิตร AI รายใหญ่ของ AWS เปิดตัว Claude Fable 5.1 และ Mythos 5.1 — [Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-1)

Anthropic ซึ่ง Amazon เป็นนักลงทุนเชิงกลยุทธ์รายใหญ่และเป็นผู้ให้บริการโมเดล Claude ผ่าน AWS Bedrock เปิดตัว Claude Fable 5.1 (ให้ใช้งานทั่วไป) และ Claude Mythos 5.1 (จำกัดเฉพาะ trusted-access) เมื่อวันที่ 1 กันยายน โดย Fable 5.1 ลดต้นทุนงาน agentic ลงได้ถึง 45% และลด false positive ด้านความปลอดภัยใน Claude Code ลงราว 60% ทั้งสองรุ่นให้บริการผ่าน AWS ควบคู่กับแพลตฟอร์มของ Anthropic เอง

ความสัมพันธ์แบบ strategic investor ระหว่าง Amazon กับ Anthropic ทำให้ AWS ไม่ได้เป็นเพียงผู้ให้บริการคลาวด์ แต่มีผลประโยชน์โดยตรงกับความสำเร็จของ Claude การลดต้นทุนงาน agentic ลง 45% มีนัยสำคัญต่อ AWS โดยตรง เพราะทำให้ลูกค้า Bedrock ใช้งานหนักขึ้นได้โดยไม่เพิ่มค่าใช้จ่ายตามสัดส่วน หนุนทั้งรายได้และความสามารถแข่งขันกับ Azure/GCP ทีมที่ใช้ Claude ผ่าน Bedrock ควรตรวจสอบความพร้อมใช้งานของ Fable 5.1/Mythos 5.1 บน AWS และประเมินการย้ายจาก Fable 5 เพื่อรับส่วนลด cache-read ทันที
