NVIDIA ประกาศความร่วมมือกับผู้ให้บริการดาต้าเซ็นเตอร์ออสเตรเลีย 8 ราย ได้แก่ Firmus, Sharon AI, IREN, Megaport, ResetData, CDC, NextDC และ AirTrunk ตั้งเป้าสร้าง "AI factory" รวมกำลังไฟสูงสุด 2 กิกะวัตต์ภายในปี 2027 โดย IREN จะใช้แคมปัส Bundey ขนาด 800MW เป็นฐาน ส่วน Sharon AI วางแผนติดตั้ง GPU ของ NVIDIA มากถึง 68,000 ตัว ตัวเลขนี้ใหญ่กว่ากำลังการผลิตดาต้าเซ็นเตอร์ทั้งหมดที่ออสเตรเลียมีอยู่ในปัจจุบัน (ราว 1.6GW) สะท้อนแนวคิด "AI sovereignty" ที่ประเทศไม่มี hyperscaler ของตัวเองอาศัยพันธมิตรกับผู้ผลิตชิปรายใหญ่สร้างขีดความสามารถประมวลผลในประเทศ

### 4. Apple เปิดฟีเจอร์พิสูจน์ภาพถ่ายไม่ผ่านการตัดต่อ AI — [TechCrunch](https://techcrunch.com/2026/09/09/apple-has-a-new-way-prove-your-iphone-photos-arent-ai-slop/)

Apple เปิดตัว "Apple Reference Image" ฟีเจอร์ใหม่สำหรับ iPhone 18 Pro ที่พิสูจน์ความแท้ของภาพถ่าย โดยเซนเซอร์กล้องจะบันทึกข้อมูลที่เซ็นรับรอง (signed sensor data) แล้วส่งผ่าน Private Cloud Compute แปลงเป็น "ภาพเนกาทีฟดิจิทัล" ที่แก้ไขไม่ได้ เก็บไว้ในแอป Photos เพื่อเทียบกับไฟล์เวอร์ชันอื่นๆ ว่ามีการแก้ไขหรือไม่ Apple ระบุว่าฟีเจอร์นี้สำคัญมากสำหรับช่างภาพข่าวและนักข่าว พร้อมเปิด API ให้นักพัฒนา third-party integrate เข้าแอปตัวเองได้ และประกาศจะรองรับมาตรฐาน SynthID เพื่อช่วยตรวจสอบภาพที่สร้างหรือแก้ไขด้วย AI ด้วย
