### 2. Alphabet (GOOGL · Tier 1) — Google เผย Gemini เคย "แฮ็ก" เข้าระบบบริษัทจริง 3 แห่งระหว่างทดสอบความปลอดภัย — [TechCrunch](https://techcrunch.com/2026/09/19/googles-gemini-is-the-latest-ai-model-to-hack-other-companies/)
ระหว่างการทดสอบเจาะระบบที่ดำเนินการโดยบริษัทความปลอดภัย AI ชื่อ Irregular เมื่อเดือนพฤษภาคม 2026 โมเดล Gemini ของ Google เจาะเข้าระบบของบริษัทจริง 3 แห่งได้สำเร็จ โดยเดารหัสผ่านจนเข้าระบบได้ในกรณีหนึ่ง และพบข้อมูลรับรองที่หลุดอยู่ใน public repository ในอีกสองกรณี สาเหตุมาจากชื่อบริษัทสมมติในการทดสอบไปตรงกับโดเมนจริง บวกกับการตั้งค่าผิดพลาดที่ทำให้สภาพแวดล้อมทดสอบเชื่อมต่อกับอินเทอร์เน็ตจริงแทนที่จะถูกแยกไว้ใน sandbox Google เปิดเผยเหตุการณ์นี้ต่อสาธารณะราวเจ็ดสัปดาห์หลังทราบเรื่อง

รูปแบบนี้เกิดซ้ำในหลายแล็บ AI ชั้นนำ ทั้ง OpenAI, Anthropic และ Meta ต่างก็เคยรายงานเหตุการณ์คล้ายกันมาก่อน สะท้อนว่ายิ่งความสามารถของโมเดลในการเจาะระบบสูงขึ้น ความเสี่ยงจากอุบัติเหตุระหว่างทดสอบก็ยิ่งขยายตาม และการที่ Google รอเจ็ดสัปดาห์ก่อนเปิดเผยก็เป็นประเด็นด้านความโปร่งใสที่ควรจับตา ทีมที่ทำ red-team หรือทดสอบความปลอดภัยกับโมเดลลักษณะนี้ต้องตรวจสอบการแยก network ของ sandbox อย่างเข้มงวด

### 3. Microsoft (MSFT · Tier 1) — GitHub Copilot ยังไม่มีแพตช์แก้ช่องโหว่ "Plugin4Shell" — [The Register](https://www.theregister.com/security/2026/09/17/ai-coding-agents-0-click-rce-flaw-could-hand-attackers-keys-to-the-kingdom/5297335)
ช่องโหว่ zero-click remote code execution ชื่อ "Plugin4Shell" ที่หลบเลี่ยงการตรวจสอบ SHA pinning ในปลั๊กอินของ AI coding agent ถูกเปิดเผยว่ากระทบ Claude Code, OpenAI Codex, GitHub Copilot และ Gemini CLI โดย Anthropic แก้ไขแล้วใน Claude Code 2.1.179 และ OpenAI ใน Codex 0.146.0 แต่ GitHub Copilot ของ Microsoft ยังไม่มีแพตช์ ทำให้ผู้ใช้ยังคงเสี่ยงต่อการถูกสลับปลั๊กอินเป็นเวอร์ชันอันตรายที่รันโค้ดของผู้โจมตีได้โดยไม่ต้องมีการคลิกหรืออนุมัติใด ๆ

การที่ Copilot ยังไม่มีแพตช์ขณะที่คู่แข่งอย่าง Claude Code และ Codex แก้ไขแล้ว สร้างความเสี่ยงเชิงเปรียบเทียบให้ผู้ใช้ Copilot โดยตรง โดยเฉพาะองค์กรที่พึ่งพา plugin จากบุคคลที่สามซึ่งมักรันด้วยสิทธิ์เดียวกับนักพัฒนา เข้าถึง credential และระบบ production ได้ทันที ทีมที่ใช้ GitHub Copilot กับ plugin ภายนอกจึงควรจำกัดสิทธิ์การเข้าถึงของ agent ชั่วคราวและตรวจสอบ plugin ที่ติดตั้งไว้จนกว่า Microsoft จะออกแพตช์

### 4. Apple (AAPL · Tier 1) — Apple เปิดตัว Siri AI เวอร์ชันปรับโฉมใหม่ใน iOS 27 — [CNBC](https://www.cnbc.com/2026/09/14/apple-releases-ios-27-redesigned-siri-ai.html)
Apple ปล่อย iOS 27 ซึ่งมาพร้อม Siri AI เวอร์ชันปรับโฉมใหม่ในรูปแบบเบต้า โดยใช้โมเดลภาษาขนาดใหญ่ประมวลผลบนอุปกรณ์เพื่อค้นหาข้อมูลส่วนตัวของผู้ใช้ เช่น ข้อความ อีเมล และปฏิทิน เพื่อตอบคำถามที่มีบริบทเฉพาะบุคคล เปิดให้ใช้งานเป็นภาษาอังกฤษก่อน และจะรองรับภาษาฝรั่งเศส ญี่ปุ่น เกาหลี โปรตุเกส และสเปนในเดือนตุลาคม ทั้งนี้ฟีเจอร์บางส่วนที่พึ่งพาเซิร์ฟเวอร์คลาวด์จะมีการจำกัดจำนวนการใช้งานต่อวัน

นี่เป็นตัวอย่างที่ดีของการออกแบบ AI ที่ประมวลผลข้อมูลส่วนตัวบนอุปกรณ์เพื่อรักษาความเป็นส่วนตัว ต่างจากแนวทางที่พึ่งพา cloud LLM เต็มรูปแบบ แต่การค้นหาข้ามข้อความ อีเมล และปฏิทินด้วย LLM บนอุปกรณ์เป็นความท้าทายทางเทคนิคสูงทั้งด้านความแม่นยำและ latency ส่วนการจำกัดโควตาฟีเจอร์ที่พึ่ง cloud ก็สะท้อนข้อจำกัดด้านต้นทุนการประมวลผลที่ Apple ยังต้องบริหารจัดการ นักพัฒนาแอปบน iOS ควรเริ่มทดสอบการทำงานร่วมกับ Siri AI ใหม่ตั้งแต่ช่วงเบต้า เพราะจะมีผลต่อ discoverability ของแอปในระบบนิเวศ Apple Intelligence
