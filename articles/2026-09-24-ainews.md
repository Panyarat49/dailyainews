Anthropic ประกาศว่า Claude ค้นพบระบบเอนไซม์ที่ไม่เคยมีใครระบุมาก่อนในดีเอ็นเอของแบคทีริโอเฟจ (ไวรัสที่ติดเชื้อแบคทีเรีย) โดยตั้งชื่อว่า ART (array-associated reverse transcriptases) ซึ่งมีลักษณะคล้าย CRISPR ตรงที่มี array ของดีเอ็นเอซ้ำเรียงกันเป็นระเบียบอยู่ข้างยีนของเอนไซม์ การค้นพบนี้เกิดจากฝูง agent ของ Claude ราว 950 ตัวที่คัดกรองรีเวิร์สทรานสคริปเทสกว่า 200,000 ตัว จนเหลือ 20 ระบบที่น่าสนใจที่สุดสำหรับให้มนุษย์ตรวจสอบต่อ นับเป็นผลลัพธ์ชิ้นแรกจากแล็บชีววิทยาใหม่ของ Anthropic แม้หน้าที่ทางชีวภาพที่แท้จริงของเอนไซม์นี้จะยังไม่มีใครทราบ

เคสนี้เป็นตัวอย่างสอนที่ดีว่า AI agent ทำงาน "screening" ขนาดใหญ่ที่มนุษย์ทำเองไม่ไหวได้จริง แต่ผลลัพธ์ยังเป็นเพียงการตั้งสมมติฐาน ไม่ใช่การพิสูจน์ — จุดที่น่าสนใจทางเทคนิคคือการออกแบบ pipeline ให้ agent นับ repeat เทียบกับวรรณกรรมและกรองซ้ำก่อนส่งรายงาน ซึ่งเป็นรูปแบบ AI-for-science ที่ scale ได้จริง ไม่ใช่แค่ demo และ pattern การ orchestrate agent จำนวนมากพร้อม guardrail แบบนี้สามารถนำไปปรับใช้กับงาน data-mining ขนาดใหญ่ในองค์กรอื่นได้เช่นกัน

### 2. OpenAI เปิดตัว GPT-6 Sol และ GPT-6 Luna พร้อมอัปเกรด ChatGPT Voice — [OpenAI](https://openai.com/index/introducing-gpt-6-sol-and-luna/)

OpenAI ขยายตระกูล GPT-6 ด้วยสองโมเดลใหม่: Sol สำหรับงาน coding และ agentic tasks ที่ซับซ้อน และ Luna โมเดลขนาดเล็กประหยัดสำหรับงานปริมาณมากอย่างการสรุปเอกสารหรือดึงข้อมูล ราคา API ถูกลงราวครึ่งหนึ่งจาก GPT-5.6 (Sol อยู่ที่ 2/10 ดอลลาร์ต่อล้านโทเคน อินพุต/เอาต์พุต) พร้อมกันนี้ ChatGPT Voice ก็ได้รับการอัปเกรดใหญ่ทั่วโลก รองรับปลั๊กอินอีเมลและปฏิทิน โดยขับเคลื่อนด้วยโมเดลตระกูล Astra/Sol/Luna ทั้งหมด สื่อไทยอย่าง Blognone รายงานข่าวนี้ในวันเดียวกัน

ควรใช้เคสนี้สอนเรื่อง trade-off ระหว่างคุณภาพกับต้นทุนโมเดล เพราะ Luna ถูกออกแบบมาเฉพาะงาน routine ต่างจาก Sol ที่เน้นงาน agentic ซึ่งสะท้อนแนวโน้มตลาดที่โมเดลเริ่มแตกสายตาม use-case ชัดเจนขึ้น — ราคาที่ถูกลงครึ่งหนึ่งพร้อม error rate ที่ลดลงราวครึ่งหนึ่งเป็นสัญญาณว่าการแข่งขันด้านต้นทุนต่อโทเคนกำลังเข้มข้นไม่แพ้การแข่งความสามารถ ทีมที่ใช้ GPT ผ่าน API ควรทดสอบสลับไปใช้ Sol/Luna ทันทีสำหรับงาน agentic coding และ batch-processing ตามลำดับ เพราะต้นทุนที่ลดลงมากพอจะกระทบ cost structure ของ production pipeline จริง
