### 1. Alphabet (GOOGL US · Tier 1) — Google ทดสอบ AI compute ในวงโคจรครั้งแรกผ่าน Project Suncatcher — [Google](https://blog.google/innovation-and-ai/models-and-research/google-research/google-project-suncatcher-facts/)

Google ประกาศแผนส่งดาวเทียมต้นแบบที่บรรทุก TPU รุ่น Trillium จำนวน 4 ตัว ขึ้นสู่วงโคจรต่ำในวันที่ 1 ตุลาคม 2026 ด้วยจรวด SpaceX ภารกิจ Transporter-18 ร่วมกับบริษัท Planet เพื่อทดสอบว่าชิป AI จะทนต่อรังสี แรงสั่นสะเทือน และความท้าทายด้านการระบายความร้อนในสุญญากาศได้หรือไม่ เป้าหมายระยะยาวคือการใช้พลังงานแสงอาทิตย์ที่ต่อเนื่องในอวกาศซึ่งให้พลังงานมากกว่าบนโลกถึง 8 เท่า

เป็นตัวอย่างที่ดีสำหรับสอนเรื่องข้อจำกัดทางฟิสิกส์ของ AI ที่ไม่ได้อยู่แค่ในซอฟต์แวร์ ฝั่งผู้เชี่ยวชาญมองว่านี่เป็นเพียงการทดสอบความเป็นไปได้ทางวิศวกรรม แต่หากสำเร็จอาจเปิดทางให้คิดโครงสร้าง compute แบบใหม่ในอีก 5-10 ปีข้างหน้า ด้านโปรแกรมเมอร์มองว่ายังไม่กระทบงานวันนี้ แต่ควรจับตาระยะยาว เพราะจะเปลี่ยนสมมติฐานเรื่อง latency ของ inference บนโครงสร้างพื้นฐานแบบกระจายสุดขั้ว

### 2. Alibaba (BABA US / 9988 HK · Tier 1) — เปิดตัวชิป AI "Zhenwu V900" อ้างแรงสุดในจีน — [CNBC](https://www.cnbc.com/2026/09/22/alibaba-ai-alibabacloud-zhenwu-v900-.html)

ในงาน Apsara Conference ซีอีโอ Eddie Wu เปิดตัวชิป AI accelerator รุ่น Zhenwu V900 หน่วยความจำ 216GB รองรับ FP8/FP4 อ้างว่าแรงกว่ารุ่นก่อน (Zhenwu M890) ถึง 3 เท่า วางแผนผลิตเชิงพาณิชย์ไตรมาส 1 ปี 2027 พร้อมประกาศแผนขยายดาต้าเซ็นเตอร์รวม 20GW ภายในปี 2032

มุมมองวิชาการมองว่านี่เป็นกรณีศึกษาเรื่องการพึ่งพาตนเองด้านเซมิคอนดักเตอร์ของจีนภายใต้ข้อจำกัดการส่งออกชิปจากสหรัฐฯ ผู้เชี่ยวชาญด้าน AI ชี้ว่าตัวเลขประสิทธิภาพและการรองรับ FP8/FP4 บ่งชี้ว่า Alibaba ไล่ตามสถาปัตยกรรมระดับ Blackwell/Rubin ได้ใกล้ขึ้น แม้ยังไม่มี benchmark อิสระยืนยัน ด้านโปรแกรมเมอร์มองว่าหากผลิตได้จริง นักพัฒนาในจีนจะมีทางเลือกฮาร์ดแวร์ในประเทศมากขึ้น ลดการพึ่งพา Nvidia ในบางเวิร์กโหลด

### 3. Meta Platforms (META US · Tier 1) — ดัน AI agent "Muse" เป็นแกนหลักของงาน Connect 2026 — [TechCrunch](https://techcrunch.com/2026/09/23/everything-new-coming-to-metas-ai-agent-muse/)

ในงาน Connect 2026 Meta ขยายความสามารถของ AI agent "Muse" ด้วยอุปกรณ์สวมใส่รุ่นใหม่ชื่อ Charm (จี้จอเล็กแสดงอวตาร) ผูกเข้ากับแว่นตาอัจฉริยะของบริษัท และเพิ่มความสามารถใหม่ เช่น แนะนำออกกำลังกาย บันทึกมื้ออาหาร ช่วยจองนัดหมาย และช่วยช้อปปิ้ง รวมถึงขยายให้ใช้งานบน Mac ได้ อุปกรณ์ Charm มีกำหนดวางจำหน่ายทันเทศกาลปลายปีนี้

ฝั่งวิชาการมองว่านี่เป็นตัวอย่างของการออกแบบ AI companion ให้จับต้องได้ผ่านฮาร์ดแวร์แทนที่จะอยู่แค่ในแอป ผู้เชี่ยวชาญด้าน AI ตั้งข้อสังเกตว่าการผูก agent เข้ากับอุปกรณ์หลายตัวพร้อมกันเพิ่มความซับซ้อนด้านการแชร์บริบทและความเป็นส่วนตัว ด้านโปรแกรมเมอร์ชี้ว่าการขยาย Muse ไปที่ Mac อาจสื่อถึง SDK/API สำหรับนักพัฒนาบุคคลที่สามที่จะตามมา ควรติดตามเอกสารนักพัฒนาของ Meta ในไตรมาสหน้า

### 4. Microsoft (MSFT US · Tier 1) — รีบูต Copilot เป็น "super app" เน้นลูกค้าองค์กร — [CNBC](https://www.cnbc.com/2026/09/25/microsoft-copilot-ai-coding-anthropic.html)

Microsoft รวมแอป Copilot เวอร์ชันผู้บริโภคและองค์กรเข้าเป็นแอปเดียว เพิ่มฟีเจอร์ chat, Code (เครื่องมือเขียนโค้ด) และ Autopilot (AI agent) โดยหันไปเน้นลูกค้าองค์กรที่จ่ายตามการใช้งาน แทนที่จะแข่งขันในตลาด personal chatbot ที่ปล่อยให้ OpenAI, Google และ Meta ครองพื้นที่ต่อไป โครงการนี้ใช้เวลาพัฒนา 6 เดือนภายใต้การนำของ Jacob Andreou

มุมมองวิชาการมองว่านี่เป็นกรณีศึกษาเรื่องกลยุทธ์การวางตำแหน่งผลิตภัณฑ์ — การยอมสละตลาด consumer chatbot เพื่อโฟกัสที่จุดแข็งด้านองค์กร ผู้เชี่ยวชาญด้าน AI มองว่าการรวม chat, Code และ agent ไว้ในที่เดียวเป็นการเดิมพันว่าองค์กรต้องการแพลตฟอร์มครบวงจร แต่ก็เพิ่มความซับซ้อนเรื่องสิทธิ์เข้าถึงข้อมูลระหว่างบัญชีส่วนตัวและองค์กร ด้านโปรแกรมเมอร์แนะนำให้จับตาโมเดลราคาแบบจ่ายตามการใช้งานของ Code และ Autopilot เทียบกับคู่แข่งอย่าง Claude Code ก่อนตัดสินใจย้ายมาใช้งาน

### 5. Amazon (AMZN US · Tier 1) — เปิด Seller Central ให้ AI agent ภายนอกอย่าง Claude เข้าถึงได้ — [Amazon](https://www.aboutamazon.com/news/innovation-at-amazon/seller-assistant-plugin-amazon-quick-claude)

ในงาน Accelerate 2026 Amazon เปิดตัว Selling Partner plugin ที่ให้ผู้ขายจัดการสินค้าคงคลัง ราคา และรายการสินค้าผ่าน AI agent ภายนอก โดยเริ่มทดลองกับ Claude ของ Anthropic บน Amazon Bedrock พร้อมมอบสิทธิ์ใช้งาน Amazon Quick Plus ฟรี 12 เดือนให้ผู้ขายทุกบัญชีหลักทั่วโลก ระบบยังคงข้อมูลผู้ขายไว้ในโครงสร้างพื้นฐานของ Amazon และต้องได้รับอนุมัติจากผู้ขายก่อนทุกการกระทำ

มุมมองวิชาการมองว่านี่เป็นตัวอย่างที่ดีของการออกแบบ AI agent แบบ human-in-the-loop ที่ต้องขออนุญาตทุกครั้งก่อนลงมือทำ เหมาะสำหรับสอนเรื่องการกำกับดูแล agent ที่เข้าถึงระบบธุรกิจจริง ผู้เชี่ยวชาญด้าน AI มองว่าการเปิดให้ Claude เข้าถึงผ่าน Bedrock พร้อม guardrail เป็นแนวทางที่สมดุลระหว่างประโยชน์ของ agentic AI กับความเสี่ยงด้านข้อมูลธุรกิจที่ละเอียดอ่อน ด้านโปรแกรมเมอร์ชี้ว่า plugin นี้เปิดโอกาสให้นักพัฒนาที่สร้างเครื่องมือบน Claude เชื่อมต่อข้อมูล Amazon แบบ real-time ได้โดยตรง ควรศึกษาสถาปัตยกรรมนี้เป็นแนวทางสำหรับเชื่อม agent เข้ากับระบบภายในองค์กรของตัวเอง
