### 1. Microsoft (MSFT US · Tier 1) — Microsoft รวมแอป Copilot ผู้ใช้ทั่วไป/องค์กรเป็นหนึ่งเดียว เพิ่มแท็บ Code และ Autopilot — [CNBC](https://www.cnbc.com/2026/09/25/microsoft-gives-copilot-a-much-needed-overhaul-and-the-stock-deservedly-soars.html)

Microsoft รวมแอป Copilot ฝั่งผู้ใช้ทั่วไปกับฝั่งองค์กรเข้าเป็นผลิตภัณฑ์เดียวที่เน้นลูกค้าองค์กร ปิดฉากความพยายามสองปีในการสร้าง "เพื่อน AI ส่วนตัว" และยกตลาดแชทบอทผู้บริโภคให้ OpenAI, Google และ Meta แอปใหม่เพิ่มแท็บ Code (ต่อยอดจากเทคโนโลยี GitHub Copilot) สำหรับผู้ใช้ที่ไม่ใช่สายเทคนิคให้เริ่มเขียนโปรแกรมง่ายๆ ได้ และแท็บ Autopilot ให้สร้าง agent ที่ทำงานแทนใน Teams และ Outlook ได้ โดยตั้งเป้าแข่งขันกับ Anthropic โดยตรง ([รายละเอียดเพิ่มเติมเรื่อง Autopilot](https://www.cnbc.com/2026/09/25/microsoft-copilot-ai-coding-anthropic.html)) หุ้น Microsoft พุ่งขึ้นกว่า 4% ในวันประกาศ และ Microsoft 365 Copilot มีผู้ใช้แบบเสียเงินทะลุ 30 ล้านที่นั่งแล้ว

การถอยจากตลาด "personal AI companion" ที่แข่งขันดุเดือดไปโฟกัสตลาดองค์กรที่ทำกำไรชัดเจนกว่า เป็นกรณีศึกษากลยุทธ์ธุรกิจที่ดี ส่วนการรวม Code tab กับ Autopilot agent ในแอปเดียวเป็นความพยายามลด friction ระหว่างการเขียนโค้ดกับการมอบหมายงานให้ agent ทำแทน ซึ่งเป็นทิศทางเดียวกับที่ Anthropic กำลังผลักดัน ทีมที่ใช้ Microsoft 365 อยู่แล้วควรประเมินว่า Autopilot tab คุ้มค่ากับโมเดลคิดเงินตามการใช้งานหรือไม่ ก่อนขยายการใช้งานทั้งองค์กร

### 2. Alibaba (BABA US · 9988 HK · Tier 1) — Alibaba เปิดตัวชิป AI Zhenwu V900 พร้อมแผนโมเดล Qwen ขนาด 10 ล้านล้านพารามิเตอร์ — [CNBC](https://www.cnbc.com/2026/09/22/alibaba-ai-alibabacloud-zhenwu-v900-.html)

ในงาน Apsara Conference Alibaba เปิดตัว Zhenwu V900 ชิปประมวลผล AI ที่พัฒนาเอง ซึ่งบริษัทระบุว่าทรงพลังที่สุดในจีน (แรงกว่ารุ่นก่อน 3 เท่า รองรับคลัสเตอร์สูงสุด 500,000 การ์ด) พร้อมประกาศแผนพัฒนาโมเดล Qwen รุ่นถัดไปขนาด 5-10 ล้านล้านพารามิเตอร์ เทียบกับ Qwen3.8-Max ปัจจุบันที่ 2.4 ล้านล้านพารามิเตอร์ นอกจากนี้ยังตั้งเป้าขยายศูนย์ข้อมูลคลาวด์ทั่วโลกให้เกิน 20 กิกะวัตต์ภายในปี 2032 ([ยืนยันโดย Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/alibaba-unveils-zhenwu-v900-ai-accelerator-claims-its-the-most-powerful-ai-chip-in-china-accelerator-supports-500-000-chip-supercluster-with-a-10t-parameter-qwen-model-on-the-roadmap)) หุ้น Alibaba พุ่งขึ้นราว 5%

นี่คือตัวอย่างชัดเจนของ "compute sovereignty" — บริษัทจีนพัฒนาชิปเองเพื่อลดการพึ่งพา Nvidia ท่ามกลางมาตรการควบคุมการส่งออกของสหรัฐฯ การขยับขนาดโมเดลจาก 2.4 ล้านล้านไปสู่ 5-10 ล้านล้านพารามิเตอร์เป็นการก้าวกระโดดใหญ่ที่ต้องจับตาว่าคุณภาพจะเพิ่มขึ้นสมส่วนหรือเป็นเพียงตัวเลขทางการตลาด ส่วนชิปที่รองรับคลัสเตอร์ขนาดใหญ่นี้เป็นสัญญาณว่า Alibaba Cloud จะมีกำลัง compute ราคาถูกลงให้ลูกค้าองค์กรในเอเชียเลือกใช้แทน GPU ของ Nvidia มากขึ้น ทีมที่สนใจควรติดตามราคาและการรองรับ SDK เมื่อเปิดใช้จริงต้นปี 2027

### 3. Apple (AAPL US · Tier 1) — Apple เปิดตัว Siri AI เวอร์ชันใหม่พร้อมอัปเดตซอฟต์แวร์ครั้งใหญ่ — [Apple Newsroom](https://www.apple.com/newsroom/2026/09/major-updates-for-apples-software-platforms-are-now-available/)

### 4. AMD (AMD US · Tier 1) — AMD ทะลุมูลค่าตลาด 1 ล้านล้านดอลลาร์ จากแรงหนุนธุรกิจ AI/data center — [CNBC](https://www.cnbc.com/2026/09/21/amd-stock-1-trillion-value.html)

หุ้น AMD พุ่งขึ้นราว 10% ระหว่างวันสู่ระดับสูงสุดเป็นประวัติการณ์ ดันมูลค่าตลาดทะลุ 1 ล้านล้านดอลลาร์เป็นครั้งแรก กลายเป็นบริษัทเซมิคอนดักเตอร์รายที่ 4 ของวงจรนี้ที่แตะระดับดังกล่าว ต่อจาก Nvidia, Broadcom และ Micron/SK Hynix แรงหนุนหลักมาจากรายได้ธุรกิจ data center ที่โต 107% เทียบปีต่อปี จากความต้องการชิป EPYC และ Instinct GPU ที่เกี่ยวข้องกับการขยายตัวของ AI
