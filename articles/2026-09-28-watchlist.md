### 1. Microsoft (MSFT · Tier 1) — ปรับโฉม Copilot ครั้งใหญ่ ด้วยเครื่องมือสร้างแอปด้วยภาษาธรรมชาติและ agent ทำงานตลอดเวลา — [CNBC](https://www.cnbc.com/2026/09/25/microsoft-copilot-ai-coding-anthropic.html)

Microsoft เปิดตัวฟีเจอร์ใหม่ในแอป Copilot ชุดใหญ่: เครื่องมือ "Code" ที่ให้ผู้ใช้สร้างแอป แดชบอร์ด และซอฟต์แวร์อื่นๆ ด้วยพรอมป์ภาษาธรรมชาติ โดยใช้เทคโนโลยีเดียวกับ GitHub Copilot และ "Autopilot" agent ทำงานตลอดเวลาที่มีตัวตนและสิทธิ์การเข้าถึงเป็นของตัวเองใน company directory สามารถติดตามช่อง Teams ประสานงานประเมินซัพพลายเออร์ หรือจัดการงานประจำโดยไม่ต้องมีคนควบคุม พร้อมฝัง Word, Excel และ PowerPoint เข้าไปใน Copilot โดยตรง ฟีเจอร์นี้ถูกมองว่าเป็นคำตอบของ Microsoft ต่อการรุกตลาดองค์กรของ Anthropic โดยตรง หุ้น Microsoft ปรับขึ้นราว 3-4% หลังประกาศ

เป็นตัวอย่างที่ดีของวิวัฒนาการจาก "AI ผู้ช่วย" ไปสู่ "AI ตัวแทน" ที่มีตัวตนและสิทธิ์ของตัวเองในองค์กร การให้ Autopilot มี identity แยกพร้อม permission ที่ควบคุมได้เป็นการออกแบบที่จริงจังกว่าการสาธิตทั่วไป แต่ยังต้องรอดูว่าการจัดการสิทธิ์และ audit trail จะปลอดภัยแค่ไหนเมื่อใช้งานจริง ทีมพัฒนาที่จะปล่อยให้พนักงานทั่วไปเข้าถึงเครื่องมือ "Code" ในวงกว้างควรเตรียมประเมิน governance สำหรับแอปที่ non-engineer สร้างขึ้นเอง เพื่อป้องกัน shadow IT ระลอกใหม่

### 2. AMD (AMD · Tier 1) — มูลค่าตลาดทะลุ 1 ล้านล้านดอลลาร์เป็นครั้งแรก — [CNBC](https://www.cnbc.com/2026/09/21/amd-stock-1-trillion-value.html)

มูลค่าตลาดของ AMD ทะลุ 1 ล้านล้านดอลลาร์เป็นครั้งแรก หลังหุ้นปรับขึ้นต่อเนื่อง 5 วันติด ทำให้ AMD กลายเป็นบริษัทเซมิคอนดักเตอร์สหรัฐฯ รายที่ 4 ที่ทำได้ (ต่อจาก Nvidia, Broadcom และ Micron) แรงหนุนหลักมาจากดีมานด์ชิป AI และรายได้ที่เติบโตราว 50% ในปีนี้

เป็นกรณีศึกษาที่ดีเรื่องการประเมินมูลค่าบริษัทเทคโนโลยีในยุค AI boom เทียบกับเส้นทางของ Nvidia, Broadcom และ Micron ที่ผ่านหลักล้านล้านมาก่อน การเติบโตของรายได้ที่มาจากดีมานด์ชิป AI เป็นหลักสะท้อนว่าตลาดเชื่อว่า AMD จะเป็นทางเลือกที่สองรองจาก Nvidia ในตลาด accelerator ระดับ data center ได้จริง ไม่ใช่แค่กระแสหุ้น อย่างไรก็ตาม ทีมที่วางแผน infra ระยะยาวควรจับตาความพร้อมของ ROCm software stack เทียบกับ CUDA เพราะมูลค่าตลาดที่สูงขึ้นไม่ได้แปลว่า tooling จะสมบูรณ์ตามไปด้วยในทันที

### 3. Alibaba (BABA · Tier 1) — เปิดตัวชิป AI รุ่นใหม่ Zhenwu V900 แรงขึ้น 3 เท่า — [CNBC](https://www.cnbc.com/2026/09/22/alibaba-ai-alibabacloud-zhenwu-v900-.html)

ในงาน Apsara Conference ที่เมืองหางโจว ซีอีโอ Eddie Wu เปิดตัวชิปเร่งความเร็ว AI รุ่นใหม่ Zhenwu V900 ซึ่งมีประสิทธิภาพสูงกว่ารุ่นก่อนหน้า (Zhenwu M890) ถึง 3 เท่า มาพร้อมหน่วยความจำบนชิป 216GB และแบนด์วิดท์เชื่อมต่อระหว่างชิป 1,200GB/s ขยายเป็นคลัสเตอร์ได้ถึง 500,000 ชิ้นสำหรับฝึกโมเดลระดับ frontier พร้อมประกาศแผนขยายศักยภาพ data center ของ Alibaba Cloud ทั่วโลกให้เกิน 20 กิกะวัตต์ภายในปี 2032 โดยตั้งเป้าผลิตเชิงพาณิชย์ในไตรมาสแรกปี 2027

เป็นตัวอย่างที่ดีของผลกระทบจากมาตรการควบคุมการส่งออกชิปสหรัฐฯ ต่อการพัฒนาเทคโนโลยีในจีน และการแข่งขันด้าน compute ระดับภูมิรัฐศาสตร์ ตัวเลขสเปกอย่างหน่วยความจำและแบนด์วิดท์ใกล้เคียงสถาปัตยกรรมระดับ Nvidia Blackwell/Rubin แต่ยังต้องรอการยืนยันจาก benchmark อิสระมากกว่าตัวเลขที่บริษัทแถลงเอง ทีมที่พัฒนาโมเดลบน stack ของ Alibaba Cloud ควรจับตาความพร้อมของ tooling และ compiler เพราะการย้าย workload จาก CUDA มายังระบบนิเวศอื่นมักมีต้นทุนด้านวิศวกรรมสูงกว่าที่ตัวเลขฮาร์ดแวร์บ่งชี้

### 4. Meta Platforms (META · Tier 1) — เดินหน้าดัน Muse เป็นหัวใจงาน Connect 2026 — [TechCrunch](https://techcrunch.com/2026/09/23/everything-new-coming-to-metas-ai-agent-muse/)

Mark Zuckerberg เปิด keynote งาน Meta Connect 2026 ด้วยการประกาศฟีเจอร์ใหม่จำนวนมากสำหรับ Muse: โมเดล "Muse Realtime Avatar" ที่ให้ผู้ใช้สร้างอวาตาร์และวิดีโอคอลกับ agent ได้แบบเรียลไทม์, การเชื่อมต่อกับแว่นตาอัจฉริยะของ Meta, อุปกรณ์พวงกุญแจ "Charm" ที่จะเริ่มจำหน่ายเดือนธันวาคม, ความร่วมมือกับพันธมิตรค้าปลีกรายใหม่ (Best Buy, Gap, Sephora, Walmart, Wayfair, Expedia, Instacart) และไคลเอนต์บน Mac ที่ให้ Muse ควบคุมแอปพลิเคชันใดก็ได้บนเครื่อง

เป็นตัวอย่างที่ดีของทิศทางการออกแบบ multimodal agent ที่ผสาน avatar เสียง และอุปกรณ์สวมใส่เข้าด้วยกัน แต่การผลักดันให้ Muse ทำงานข้ามอุปกรณ์พร้อมสิทธิ์ควบคุมแอปพลิเคชันจริงหมายถึงพื้นที่เสี่ยงด้าน privacy และ permission ที่กว้างขึ้นมาก เทียบเท่าระดับ OS-level agent นักพัฒนาที่ต้องการผนวกบริการกับ Muse ผ่านพาร์ทเนอร์ค้าปลีกควรศึกษาข้อกำหนด API และ permission model ของ Meta ตั้งแต่ตอนนี้ เพราะความซับซ้อนด้าน security สูงกว่าการต่อ API ทั่วไปมาก
